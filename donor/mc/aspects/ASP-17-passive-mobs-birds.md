## 0. Главное коротко

1. **Почти вся еда-приманка у нас отсутствует.** В 1.21.1 корову и овцу приманивает и сводит **только пшеница**, свинью —
   **морковь, картофель, свёкла**, курицу — **семена** (пшеницы, дыни, тыквы, свёклы, факелоцвета, кувшинки) [data
   `tags/item/*_food.json`]. В нашем объёме есть только **семена пшеницы** (трава, 12.5 %, ASP-06). Значит, сразу работают
   приманка и размножение **кур**. Для коров и овец нужна пшеница — это грядка и посев, отдельный аспект (§16). Морковь
   выпадает только с зомби: 2.5 % при убийстве игроком, из них ⅓ — морковь (ASP-18) [data `entities/zombie.json`].
2. **Скорость мобов зависит от квадрата атрибута.** Цель задаёт `forward = speed·attr`, а `travel` умножает этот же вход
   ещё раз на `speed·attr`. Установившаяся скорость на траве — `0.98·(m·s)²/0.454` блока за тик [src `MoveControl.tick`,
   `MobEntity.setMovementSpeed`, `LivingEntity.tickMovement/travel`; расчёт]. Поэтому корова бродит медленно (1.73 б/с),
   а в панике (×2.0) несётся **6.9 б/с** — быстрее бегущего игрока (5.61). Свинья: 2.70 → паника 4.22; курица: 2.70 → 5.29;
   овца: 2.28 → 3.57 (§2.2).
3. **Паника — в случайную сторону, а не от игрока,** и коротко. Цель бежит к случайной точке в радиусе 5 по горизонтали
   (±4 по высоте) и перезапускается, пока последнему урону не больше 40 тиков [src `EscapeDangerGoal`,
   `LivingEntity.getRecentDamageSource`]. После удара животное мечется ~2–4 с. Панику вызывают удар игрока, мобом и
   **кактус**, но **не падение и не утопление** [data `tags/damage_type/panic_causes`].
4. **Цели проверяются раз в 2 тика.** `canStart` у целей и счётчики «в тиках цели» идут через тик. Поэтому «шанс 1/1000» у
   поедания травы — это в среднем раз в **2000 тиков (100 с)**, а «блуждать раз в 120» — раз в ~120 игровых тиков (6 с)
   [src `MobEntity.tickNewAi`, `Goal.getTickCount`, `GoalSelector`].
5. **Дальше 32 блоков от игрока животные перестают бродить.** Счётчик `despawnCounter` сбрасывается, только пока игрок
   ближе 32. Через 100 тиков без сброса `WanderAroundGoal` больше не стартует. Сами животные **никогда не исчезают**
   (`AnimalEntity.canImmediatelyDespawn = false`) [src `MobEntity.checkDespawn`, `WanderAroundGoal.canStart`]. Вид издали:
   стадо стоит, овцы иногда щиплют траву.
6. **Размножение:** корм взрослому без перезарядки → «влюблён» 600 тиков (30 с), сердечко раз в 10 тиков. Двое влюблённых
   одного вида в пределах 8 блоков сходятся; через ~3 с (30 тиков цели) рядом (< 3 блоков) появляется детёныш. Родители получают
   перезарядку **6000 тиков (5 мин)**, детёныш растёт **24000 тиков (20 мин)**. Корм детёнышу сокращает остаток на 10 %
   [src `AnimalEntity`, `AnimalMateGoal`, `PassiveEntity`].
7. **Овца:** цвет при появлении — белая 81.84 %, чёрная, серая, светло-серая по 5 %, коричневая 3 %, розовая 0.164 %. Стрижка
   ножницами даёт **1–3** шерсти, −1 прочности ножниц. Шерсть отрастает, только когда овца съест траву: блок травы → земля
   или растение «трава» → воздух. Детёныш ест траву в 20 раз чаще, и каждый раз +60 с роста [src `SheepEntity`, `EatGrassGoal`].
8. **Курица:** падает медленно (падающая скорость ×0.6 каждый тик → предел **2.28 б/с**) и машет крыльями. Урона от падения
   у неё нет. Яйцо — раз в **6000–11999 тиков** (5–10 мин), только у взрослой [src `ChickenEntity.tickMovement`;
   data `tags/entity_type/fall_damage_immune`].
9. **Корова:** ПКМ пустым ведром по взрослой — ведро молока. Перезарядки нет. Молоко в 1.21.1 только снимает эффекты, а их у
   нас нет: выпить можно, но толку никакого [src `CowEntity.interactMob`, `MilkBucketItem`].
10. **Попугай** — летун без размножения. Перемещение в воздухе — ускорение 0.02·вход и сопротивление 0.91 по всем осям:
    ~1.7 б/с, медленное порхание [src `FlightMoveControl`, `LivingEntity.travel`; расчёт]. Почти всегда летит **на листву или
    бревно** в пределах ±3/±6 блоков, прибивается к любым **другим мобам** в 7 блоках и изредка **передразнивает зомби**.
    Спаун в ванили только в джунглях. Наше предложение — лиственные леса, спаун на кронах (§5.5, §16).
11. **Дроп** [data]: свинья — 1–3 сырой свинины; корова — 0–2 кожи и 1–3 говядины; овца — 1 шерсть своего цвета (если не
    острижена) и 1–2 баранины; курица — 0–2 пера и 1 сырая курица; попугай — 1–2 пера. **Детёныши ничего не дают.** Жареное
    мясо при смерти выпадает, только если моб горел (у нас огня пока нет). Еда [наше]: свинина и говядина лечат 3 / 8
    (сырая / жареная), курица и баранина — 2 / 6. Печь — 200 тиков.

## 1. Порядок операций: тик мирного моба (дополнение к ASP-16)

Общий тик живой сущности и моба (физика, урон, `hurtTime`, смерть) — в ASP-16 и ASP-12. Здесь показано, куда встают
особые шаги наших мобов. Источник — цепочка `tickMovement` по наследованию [src]: `LivingEntity` → `PassiveEntity` →
`AnimalEntity` → `ChickenEntity` / `ParrotEntity`, плюс `MobEntity.baseTick`.

| Шаг | Что | Источник |
|---|---|---|
| 1. `baseTick` (часть моба) | бросок звука ambient: `rand(1000) < counter++` → звук, `counter = −120` (§7.1) | `MobEntity.baseTick` |
| 2. Попугай, до ИИ | 1/400 за тик → попытка передразнить моба (§5.5) | `ParrotEntity.tickMovement` |
| 3. ИИ (`tickNewAi`) | `despawnCounter +1`; цели: в чётный тик (по `age + id`) — полный проход, в нечётный — только цели «каждый тик» (`LookAround`, `Swim`); навигация; `mobTick` (овца копирует таймер поедания; животное: если возраст ≠ 0 → любовь = 0); управления движением, взглядом, прыжком | `MobEntity.tickNewAi`, `AnimalEntity.mobTick`, `SheepEntity.mobTick` |
| 4. Прыжок, ввод ×0.98, `travel` | физика тела (ASP-16); в конце — шаг анимации ног (§7.3) | `LivingEntity.tickMovement/travel` |
| 5. Возраст | живой: возраст < 0 → +1 (рост), > 0 → −1 (перезарядка); клиентские «весёлые» частицы (§3.3) | `PassiveEntity.tickMovement` |
| 6. Любовь | возраст ≠ 0 → любовь 0; любовь > 0 → −1, при `любовь % 10 == 0` — сердечко | `AnimalEntity.tickMovement` |
| 7a. Курица | крылья (§5.2), падающая скорость ×0.6, яйцо (§5.2) | `ChickenEntity.tickMovement` |
| 7b. Попугай | крылья и ×0.6 так же (§5.5) | `ParrotEntity.flapWings` |
| 7c. Овца | клиентский таймер головы −1 (у нас один общий таймер, §5.1) | `SheepEntity.tickMovement` |

Действия игрока по мобу (ПКМ) идут в фазе ПКМ игрока (ASP-05 §11.1), удар — в фазе атаки (ASP-12 §1). Мобы тикают в фазе
сущностей `tick_world`, как выпавшие предметы (ASP-07).

### 2.2 Скорости в блоках в секунду [расчёт по `MoveControl.tick` → `MobEntity.setMovementSpeed` → `travel`; трава, скользкость 0.6]

Формула для установившегося хода по ровному: `a = 0.98·(m·s)²` за тик, `v = a / (1 − 0.6·0.91)` блока за тик.
Здесь `m` — множитель цели, `s` — атрибут скорости. Вход меньше 1, поэтому он не нормализуется. Для сверки: игрок со входом
1.0 и скоростью 0.1 даёт ровно 4.317 б/с (ASP-01/02).

| Моб | Бродит (×1.0) | Паника | Соблазн едой | За родителем | 10 блоков бродя / в панике, тиков |
|---|---|---|---|---|---|
| Свинья 0.25 | **2.70** | ×1.25 → 4.22 | ×1.2 → 3.89 | ×1.1 → 3.27 | 76 / 49 |
| Корова 0.2 | **1.73** | ×2.0 → **6.91** | ×1.25 → 2.70 | ×1.25 → 2.70 | 118 / 31 |
| Овца 0.23 | **2.28** | ×1.25 → 3.57 | ×1.1 → 2.76 | ×1.1 → 2.76 | 89 / 58 |
| Курица 0.25 | **2.70** | ×1.4 → 5.29 | ×1.0 → 2.70 | ×1.1 → 3.27 | 76 / 40 |
| Попугай: земля 0.2 / воздух 0.4 | 1.73 / **1.74** | ×1.25 → 2.70 / 2.18 | — | — | — |

Попугай в воздухе [расчёт по `FlightMoveControl` и `travel`]: вход `(0, ±0.4, 0.392)`, ускорение «не на земле» 0.02,
поэтому за тик +0.00784 вперёд и ±0.008 по высоте. Сопротивление 0.91 по всем осям (он `Flutterer`) → предел 1.74 б/с
вперёд и 1.78 б/с вверх или вниз. Гравитация выключена, пока он летит по пути (`setNoGravity(true)`).

Что чувствует игрок: прикормленная корова или овца отстаёт от идущего игрока (4.32 б/с) почти вдвое. Свинья с морковью
поспевает. Корова в панике обгоняет бегущего игрока.

### 3.2 Что делает каждая цель (параметры наших мобов)

«Тик цели» — раз в 2 игровых тика, если цель не помечена «каждый тик». `getTickCount(n) = ceil(n/2)` [src `Goal`].

- **Плавать** (`SwimGoal`, каждый тик): если уровень воды у тела выше «высоты плавания» (0.4; у тех, у кого глаза ниже 0.4, —
  0: поросёнок 0.3825 и цыплёнок 0.2975) или моб в лаве → с шансом 0.8 за тик жмёт прыжок. Тело держится у поверхности. Вода — ASP-03/ASP-15.
- **Паника** (`EscapeDangerGoal`): старт, если последнему урону ≤ 40 тиков и его тип в `#panic_causes`. В нашем объёме это
  удар игрока, удар моба (зомби, ASP-18), кактус, позже огонь и лава. Цель пути — случайная точка без штрафа (вода и т. п.)
  в радиусе 5 по горизонтали и 4 по высоте (`NoPenaltyTargeting.find(mob, 5, 4)`, ASP-16). Если моб горит и стоит не в
  твёрдой клетке, сначала ищет воду в радиусе 5 (у нас огня нет). Цель длится, пока идёт путь, потом стартует снова, пока
  урон свежий. Пока моб в панике, он не сводится (`isPanicking` отменяет размножение у обоих).
- **Размножение** (`AnimalMateGoal`): если моб влюблён, ищет ближайшего влюблённого **того же класса** в коробке ±8
  (сквозь стены), который не паникует. Каждый тик цели смотрит на пару и ведёт к ней путь. Счётчик +1 за тик цели,
  первый — в тике старта. Когда счётчик ≥ 30 (через 58 игровых тиков после старта) и расстояние² < 9 — `breed`. Цель обрывается, если пара умерла, разлюбила,
  паникует или счётчик дошёл до 60 (6 с). §3.3.
- **Соблазн** (`TemptGoal`): у цели своя перезарядка. Если она > 0, `canStart` уменьшает её и возвращает «нет». Иначе
  ищет ближайшего игрока в радиусе **10** (3D от ступней до ступней, сквозь стены) с кормом **в основной или второй руке**.
  Если игрок крадётся, радиус ×0.8 = **8** (`getAttackDistanceScalingFactor`). Каждый тик цели: взгляд на игрока
  (поворот головы до 95°/тик, наклон 40°/тик); ближе 2.5 блока (расстояние² < 6.25) — стоп, иначе путь к игроку со своей
  скоростью. При остановке (корм убран, игрок дальше 10) — путь сброшен и **перезарядка 100 тиков (5 с)**: убрал и сразу
  достал корм — животное 5 с не реагирует. Пугливость (`canBeScared`) у наших выключена.
- **За родителем** (`FollowParentGoal`): только детёныш. Ищет ближайшего **взрослого** своего класса в коробке ±8 по
  горизонтали и ±4 по высоте. Не стартует, если тот ближе 3 блоков. Раз в 10 игровых тиков прокладывает путь к нему.
  Бросает ближе 3 или дальше 16 блоков. Управлений нет, поэтому может работать вместе с «Бродить» — обе цели прокладывают
  путь в одном тике, в порядке добавления целей [вывод из `GoalSelector`; ощущение: детёныш дёргано идёт к матери].
- **Есть траву** (`EatGrassGoal`, только овца): шанс старта **1/1000** у взрослой, **1/50** у детёныша за проверку (раз в
  2 тика). Нужно: в клетке ступней — растение «трава» (`short_grass`, у нас `TALL_GRASS` 17) или под ступнями — блок травы.
  На старте таймер 40 тиков, путь стоп, сигнал клиенту «опустить голову». Через **34 тика** после старта [расчёт:
  20 тиков цели, событие на значении 2]: растение ломается без дропа (частицы и звук ломания), иначе блок травы → земля
  (частицы и звук ломания травы, соседей не обновляет) и `onEatingGrass` (§5.1). Цель держит управления 40 тиков.
  Папоротник не ест: стоя в папоротнике, ест блок травы под ним.
- **Бродить** (`WanderAroundFarGoal` → `WanderAroundGoal`): не стартует, если `despawnCounter` ≥ 100 (игрок дальше 32
  блоков больше 5 с). Шанс `1/60` за проверку → в среднем раз в 120 тиков. Цель: в воде — точка в радиусе 15/7
  (`FuzzyTargeting`); на суше — с вероятностью 0.999 `FuzzyTargeting.find(mob, 10, 7)`, иначе `NoPenaltyTargeting.find(mob,
  10, 7)`. Длится, пока идёт путь. Точки выбираются с «любовью к траве»: у животных вес клетки над блоком травы 10, иначе
  яркость − 0.5 (`AnimalEntity.getPathfindingFavor`) → стадо держится травы.
- **Смотреть на игрока** (`LookAtEntityGoal`): шанс 0.02 за проверку (в среднем раз в 100 тиков). Ближайший игрок в радиусе
  6 (попугай — 8; крадущийся ×0.8) на уровне его глаз. Смотрит 40–80 игровых тиков (20–40 тиков цели), пока игрок жив
  и в радиусе.
- **Оглядываться** (`LookAroundGoal`, каждый тик): шанс 0.02 за проверку. Случайное направление по кругу, смотрит 21–40 тиков.
  Занимает и MOVE — пока моб оглядывается, бродить он не начнёт, но «Бродить» (меньшее число) её вытеснит.
- **Лететь на дерево** (`ParrotEntity.FlyOntoTreeGoal` → `FlyGoal` → `WanderAroundFarGoal`): шанс и условие `despawnCounter` —
  как у «Бродить». Цель: в воде — точка 15/15. Затем с вероятностью 0.999 ищет в коробке ±3 по X/Z и ±6 по Y клетку
  воздуха над листвой или бревном, с воздухом над ней (не свою клетку) → летит на её нижний центр. Поиск идёт и в воде, и
  его «не нашёл» затирает водную точку (причуда). Нет такой — точка над землёй по взгляду (`AboveGroundTargeting` 8/7,
  запасная `NoPenaltySolidTargeting` 8/4/−2; ASP-16).
- **За другим мобом** (`FollowMobGoal`, попугай): старт, если в коробке ±7 есть видимый моб **другого класса**. Берёт первого
  в списке. Раз в 10 тиков: дальше 3 блоков — путь к нему; ближе — стоп. Если ещё ближе (расстояние² ≤ 3 — в коде сравнение с
  самим 3, не с 9) или тот смотрит прямо на попугая — отлетает на ту же дистанцию в обратную сторону. На время цели штраф
  воды 0. Итог: попугаи вьются около коров, кур и зомби.

### 3.3 Любовь, детёныши, рост [src `AnimalEntity`, `PassiveEntity`, `AnimalMateGoal`]

Поле `age` (у Yarn `breedingAge`): < 0 — детёныш (растёт к 0), > 0 — перезарядка (убывает к 0), 0 — готов.

1. **ПКМ кормом** по животному (`AnimalEntity.interactMob`):
   - взрослый, `age == 0`, не влюблён → корм −1, **любовь = 600**, вспышка 7 сердечек; результат SUCCESS (взмах руки);
   - детёныш → корм −1, `grow_up(toGrowUpAge(−age), forced = true)`: `toGrowUpAge(t) = (int)((t / 20) · 0.1f)` секунд → минус
     10 % остатка. Новорождённый: 24000 → 21600. Остаток < 200 тиков даёт 0 → корм тратится зря [расчёт]. Плюс 40 тиков
     «весёлых» зелёных частиц, по одной раз в 4 тика;
   - взрослый с перезарядкой или уже влюблённый → корм **не тратится**, ничего не происходит (дальше по цепочке ПКМ).
2. Пока влюблён: −1 за тик, сердечко при `любовь % 10 == 0` → 60 сердечек за 30 с. Точка — случайная по ширине ±W от центра,
   по высоте `y + rand·H + 0.5`, скорость `gauss·0.02` по осям. Урон обнуляет любовь (`applyDamage`). При `age ≠ 0` любовь
   всегда 0.
3. **Сведение:** цель «Размножение» (§3.2) у первого, кто досчитал до 30 тиков цели рядом с парой, → `breed`. Детёныш
   того же вида появляется **в точке этого родителя**, повёрнутый на 0°, `age = −24000`. Обоим родителям `age = 6000`,
   любовь 0, ещё 7 сердечек. Сфера опыта 1–7 — опыта нет, не берём.
4. Рост: +1 за тик, только пока сущность тикает (в радиусе тика, ASP-16). На 0 — взрослый: коробка пересчитывается в
   том же тике (`calculateDimensions`).
5. Тонкость «принудительного возраста» [вывод; в декомпиляции зеркала строка искажена: `int k = i - i`]. По смыслу кода
   Mojang ускоренный кормом рост копится в `forcedAge`, и когда детёныш так становится взрослым, ему ставится
   перезарядка `age = forcedAge`. Дорощенный кормом зверь не может сразу размножаться. Это P2, проверить по mcsrc.

Детёныши при спауне [src `PassiveEntity.initialize`, `SpawnHelper.populateEntities`]: в группе первый всегда взрослый,
каждый следующий — детёныш с шансом 5 %. Попугай детёнышем не бывает.

## 5. Особенности мобов

### 5.1 Овца [src `SheepEntity`, `EatGrassGoal`, `SheepWoolFeatureRenderer`, `DyeColor`; data `entities/sheep*.json`]

**Цвет при появлении** (`generateDefaultColor`, ГСЧ мира): `r = rand(100)`.

| r | Цвет | Шанс | Оттенок шерсти на модели (×0.75 от цвета красителя; у белой особый) |
|---|---|---|---|
| 0–4 | чёрная | 5 % | #151518 |
| 5–9 | серая | 5 % | #353B3D |
| 10–14 | светло-серая | 5 % | #757571 |
| 15–17 | коричневая | 3 % | #623F25 |
| 18–99 | розовая, если ещё `rand(500) == 0`, иначе белая | 0.164 % / 81.836 % | розовая #B6687F, белая #E6E6E6 |

Цвет ставится в `initialize` — при спауне генерацией и периодическим спауном. У детёныша от родителей правило своё.
**Цвет ягнёнка** (`getChildColor`): ищется рецепт крафта из двух красителей цветов родителей. Среди природных цветов
рецепт есть у пар чёрная + белая → **серая** и серая + белая → **светло-серая** [data `gray_dye`,
`light_gray_dye_from_gray_white_dye`]. Иначе 50/50 цвет одного из родителей. У нас красителей нет — делаем эту таблицу
правилом.

**Шерсть-блок.** У нас его нет, а без него стрижка бессмысленна. Свойства [src `Blocks.WHITE_WOOL`, `BlockSoundGroup.WOOL`,
`ShearsItem`]: твёрдость 0.8, инструмент не нужен, звуки группы WOOL, горит. Ножницы — скорость 5 (тег `#wool`).
Рукой ломается за **24 тика**, ножницами за **5** [расчёт f32]. Топливо в печи — 100 тиков (ASP-10). Нужны минимум 6
природных цветов (§16).

**Стрижка** (`sheared`): звук, флаг «острижена», `1 + rand(3)` предметов. Каждый — `dropItem(шерсть, +1)`: предмет на высоте
ступни + 1, скорость конструктора `(±0.1, 0.2, ±0.1)` плюс добавка `((r−r)·0.1, r·0.05, (r−r)·0.1)`, задержка подбора 10
(ASP-07 §2.2). Ножницы −1 прочности.

**Поедание травы** (`EatGrassGoal` §3.2 + `onEatingGrass`): «острижена» снимается — шерсть отрастает мгновенно в момент
поедания. У детёныша ещё `grow_up(60)` → +1200 тиков роста.
Взрослая острижённая овца на траве ест в среднем раз в 100 с — обрастает за 1–3 минуты. Ягнёнок пробует есть раз в ~5 с;
на траве он вырастает за пару минут вместо 20 [расчёт: 24000 / 1200 = 20 поеданий].

**Анимация головы при поедании** (`getNeckAngle`, `getHeadAngle`; таймер t от 40 вниз):
- шея: t 40→36 — плавно вниз, 36…4 — внизу, 4→0 — вверх. Опускание = сдвиг шарнира головы на `9 · шея` px вниз (0.5625 блока);
- наклон головы: при 4 < t ≤ 36 — `36° + 12.6°·sin((t − 4 − δ)/32 · 28.7)`, то есть ~4.6 «жевков» с периодом ~7 тиков.
  При 0 < t ≤ 4 и t > 36 — ровно 36°. Иначе — наклон взгляда моба.

**Дроп при смерти** (таблица выбирается по цвету и флагу): не острижена — 1 шерсть своего цвета + 1–2 баранины;
острижена — только 1–2 баранины.

### 5.2 Курица [src `ChickenEntity`, `ChickenEntityRenderer`, `ChickenEntityModel`, `EggItem`, `EggEntity`, `ThrownEntity`]

**Крылья и падение** (каждый тик после `travel`):
1. `dev += (на земле ? −1 : 4)·0.3`, зажим 0…1. В воздухе раскрыты сразу, на земле складываются за ~4 тика.
2. В воздухе `flapSpeed` поднимается до 1; затем `flapSpeed ×= 0.9`; `flap += flapSpeed·2`. В воздухе фаза растёт на 1.8 рад/тик
   → взмах за ~3.5 тика (~5.7 Гц).
3. Не на земле и `v.y < 0` → `v.y ×= 0.6`.
4. Угол крыла (крен) = `±(sin(flap) + 1)·dev` (0…2 рад ≈ 0…115°), значения интерполируются между тиками.

Падение [расчёт: модель с `v = 0` на старте, как в ASP-01/02]: предел **−0.11417 б/т (2.28 б/с)**. 3 блока — 29 тиков,
10 блоков — 91 тик (4.5 с), 20 — 178. Для сравнения обычное тело: 10 блоков за 18 тиков. Урона нет (тег
`fall_damage_immune`). Звука хлопанья у курицы нет: `addFlapEffects` только двигает порог.

**Яйца:** таймер `6000 + rand(6000)` при создании. Каждый тик у **взрослой** живой курицы −1. У цыплёнка таймер стоит:
проверка «не детёныш» идёт раньше уменьшения. На ≤ 0: звук `entity.chicken.egg` (1.0, pitch 0.8–1.2), яйцо в точке
ступней (`dropItem(EGG)` → скорость конструктора, задержка 10), новый таймер `6000 + rand(6000)`. Яйца стакаются по **16**.

**Бросок яйца** (P2) [src `EggItem.use`, `EggEntity`, `ThrownEntity`]: ПКМ → звук `entity.egg.throw` (0.5, pitch
`0.4/(r·0.4 + 0.8)`), снаряд 0.25×0.25, скорость 1.5 по взгляду с разбросом 1.0, гравитация 0.03, сопротивление 0.99
(в воде 0.8). При попадании: 8 частиц предмета. С шансом 1/8 появляется цыплёнок (`age −24000`), из этих случаев в 1/32 —
четыре. По сущности — урон 0 (только толчок и вспышка). Яйцо −1 из стопки.

Цыплёнок — коробка 0.2×0.35. Жокеев нет.

### 5.5 Попугай [src `ParrotEntity`, `FlightMoveControl`, `BirdNavigation`, `FlyGoal`, `FollowMobGoal`, `ParrotEntityModel`]

- **Полёт.** Навигация `BirdNavigation`: путь по воздуху. Валидная точка — клетка с твёрдым верхом. Через двери не ходит,
  в открытые входит, плавать может. Пока путь идёт, `FlightMoveControl` каждый тик:
  1. выключает гравитацию;
  2. разворачивает yaw к точке (до 90°/тик) и pitch (до 10°/тик);
  3. ставит скорость `m·flying_speed` в воздухе или `m·movement_speed` на земле;
  4. ставит вертикальный вход ±той же скорости по знаку разницы высот.

  Путь кончился → гравитация включается, тело плавно оседает: предел **1.92 б/с** [расчёт: `(v − 0.08)·0.91·0.6`].
  Урона от падения нет. Счёт шагов ног учитывает и вертикаль (`updateLimbs(flutter = true)`).
- **Крылья** — как у курицы (§5.2), но раскрыты, пока он не на земле и **не верхом**. Звук `entity.parrot.fly` (0.15) идёт,
  когда тело над воздухом и «пройденный путь» перевалил порог `путь + dev/2` (`Entity.addAirTravelEffects`).
- **Цели дикого** — §3.1. Остальное — только у приручённого, не берём.
- **Передразнивание** (P2): каждый тик шанс 1/400 → с шансом ½ берётся случайный моб из списка «враждебных» в ±20 блоках.
  Если он не беззвучный — звук «попугай-имитация» этого моба, громкость 0.7. В нашем объёме это зомби
  (`entity.parrot.imitate.zombie` = звук ambient зомби, pitch 1.8, громкость 0.6). Ещё ambient попугая с шансом 1/1000
  заменяется имитацией случайного моба из всего списка (36 видов), кроме мирной сложности. У нас — только зомби, других
  звуков нет. Это подсказка игроку «рядом зомби».
- **Варианты окраса** — 5, равновероятно при спауне: красно-синий, синий, зелёный, жёлто-синий, серый. Текстуры свои, 32×32.
- **Не толкает игрока** (`pushAway` пропускает игроков), сам толкается.
- **Где живёт в ванили** [data `worldgen/biome/*.json`]: только `jungle` (вес 40 из 91, группа 1–2) и `bamboo_jungle` (40
  из 170). Спаун на блоке из `#parrots_spawnable_on` (трава, листва, брёвна, воздух) по карте высот **с листвой**
  (`MOTION_BLOCKING`): обычно на кронах. Свет > 8. Джунглей у нас нет — предложение в §6.3.
- Не берём: сидение, плечо, танцы у проигрывателя, приручение, отравление печеньем.

### 6.1 Дроп при смерти [data `loot_table/entities/*.json`; src `LivingEntity.drop/dropLoot/shouldDropLoot`, `Entity.dropStack`]

Счёт «a–b» — равновероятное целое от a до b включительно (ASP-06 §2.2). Пулы независимы. Добыча выпадает **в тике смерти**
(`onDeath` → `drop`), а не через 20 тиков, когда тело исчезает. Каждый стек — отдельный предмет в точке ступней моба, со
скоростью конструктора `(±0.1, 0.2, ±0.1)` и задержкой подбора 10 (ASP-07 §2.2). Таблица срабатывает и без игрока — от
кактуса или падения. Без игрока не выпадает только опыт, а его у нас нет. **Детёныш не роняет ничего.**

- **Где:** клетка над картой высот `MOTION_BLOCKING_NO_LEAVES` (земля под деревьями, не кроны). Под ней — **блок травы**

- **Pitch** взрослого: `(r − r)·0.2 + 1` (0.8–1.2, треугольное). Детёныша: `(r − r)·0.2 + 1.5` (1.3–1.7): писк. У попугая
  всегда 0.8–1.2. Множится на pitch варианта из `sounds.json`. Шаги идут с фиксированным pitch 1.0 и громкостью 0.15.
- **Категория** NEUTRAL. Затухание — общее, до 16·громкость блоков (ASP-13).
- **Ambient** [src `MobEntity.baseTick`, `AnimalEntity.getMinAmbientSoundDelay = 120`]. Каждый тик, пока жив:
  `rand(1000) < счётчик`, затем `счётчик += 1`. Сработало → звук и `счётчик = −120`. Звук урона тоже ставит −120.
  Интервал между звуками [расчёт]: среднее **160 тиков (8.0 с)**, 10–90 % — 135–188 тиков. Первый звук после появления
  (счётчик 0) — в среднем через 40 тиков.
- **Урон и смерть:** звук урона только при полном ударе. При смертельном — звук смерти вместо урона (ASP-12 §2).
- **Шаги** [src `Entity.move`]: путь копится как `|Δ|·0.6`. Шаг звучит при переходе через целое число, только на земле → раз в
  ~1.67 блока. Корова бредёт — шаг раз в ~19 тиков, в панике — раз в ~5 тиков.
- Свои звуки — CC0/CC-BY по этим событиям и числу вариантов (`../decisions.md`). Ванильная раскладка «урон = те же файлы,
  что ambient» у свиньи и овцы — это ощущение: свинья «хрюкает» от удара. Повторить подбором своих файлов.

### 7.3 Анимации [src `QuadrupedEntityModel.setAngles`, `LimbAnimator`, `LivingEntity.updateLimbs`, модели выше]

- **Шаг ног:** `скорость_ног += (min(4·|Δxz|, 1) − скорость_ног)·0.4` за тик; `фаза += скорость_ног`. У летунов в |Δ| входит
  и Y. В кадре: `фаза − скорость·(1 − α)`, скорость интерполируется, у детёныша фаза ×3, при езде и смерти ноги стоят.
  Угол (наклон) ноги = `cos(фаза·0.6662 + φ)·1.4·скорость`. У четвероногих φ = 0 у правой задней и левой передней, φ = π у
  двух других (диагональная рысь). У курицы — две ноги со сдвигом π.
  Числа [расчёт]: свинья бредёт — размах ±43°, цикл 17.5 тика; корова бредёт — ±28°, 27 тиков; паника — ±80°, 9.4 тика.
- **Голова:** поворот = (`headYaw − bodyYaw`, по модулю 360), наклон = наклон взгляда. Голова поворачивается не дальше
  75° от тела, взгляд меняется до 10°/тик по yaw и 40°/тик по pitch (`MobEntity`, ASP-16).
- **Овца ест** — §5.1. **Курица машет** — §5.2: крен крыльев `±(sin(flap)+1)·dev`.
- **Попугай** (позы по состоянию):
  - СТОИТ (на земле): ноги шагают как у курицы, на это накладывается ПОЛЁТ без поджатых ног;
  - ПОЛЁТ (не на земле): все части приподняты на `0.3·прогресс_крыльев` px. Здесь «прогресс» = `(sin(flap)+1)·dev`, как у
    курицы. Крылья — крен ∓(0.0873 + прогресс). Хвост качается `1.015 + cos(фаза·0.6662)·0.3·скорость`. Ноги поджаты
    (+40° наклона);
  - СИДИТ и ТАНЦУЕТ — не берём.
- **Урон и смерть** — общие (ASP-16, ASP-12 §7.1):
  - красная вспышка 10 тиков;
  - падение набок на `min(1, √((deathTime + α − 1)/20·1.6))·90°`, то есть 90° к ~13.5 тику [расчёт: 2 → 25°, 4 → 44°,
    8 → 67°, 12 → 84°];
  - на 20-м тике тело убирается с облачком частиц.
- **Сердечки, весёлые частицы, крошки травы** — система частиц (ASP-13).

## 8. Граничные случаи и мелочи, которые чувствует игрок

1. Одна группа — **один вид**: при генерации кусок даёт «стадо из 4 свиней», а не смешанное стадо.
2. Ударил — зверь убегает **в случайную сторону**, иногда прямо на игрока или мимо него, и через 2–4 с успокаивается.
   Каждый новый удар продлевает панику.
3. Корова в панике бегает быстрее бегущего игрока (6.9 против 5.6 б/с). Курицу и свинью догнать легко.
4. Падение в яму паники **не вызывает**, а кактус вызывает: корова, задевшая кактус, мечется и снова на него натыкается.
5. Прикормленные животные держатся в 2.5 блока от игрока и отстают от идущего игрока. Убрал корм в слот — они встают. Достал
   его снова в течение 5 с — не реагируют (перезарядка соблазна).
6. В приседе животные замечают корм с 8 блоков, а не с 10. Смотрят на игрока с 4.8 блока, а не с 6.
7. Корм во **второй руке** тоже приманивает.
8. Кормить можно только «готового»: влюблённый или с перезарядкой корм не берёт, предмет не тратится. Детёныш берёт корм
   всегда, но в последние 10 с роста — впустую.
9. Сводятся только одинаковые виды и только если оба влюблены и никто не паникует. Удар по влюблённому гасит любовь.
10. Детёныш рождается там, где стоял один из родителей, — бывает, внутри второго родителя, и их расталкивает.
11. Ягнёнок на траве вырастает за пару минут, а не за 20.
12. Острижённая овца обрастает **в момент поедания**, мгновенно. Под ней появляется пятно земли.
13. Овца в «траве»-растении съедает растение, а не дёрн. В папоротнике — съедает дёрн под папоротником.
14. Курица с обрыва планирует со скоростью ~2.3 б/с и выживает с любой высоты. Свинья и корова разбиваются, как игрок:
    4+ блока — урон.
15. Цыплёнок яйца не несёт. Таймер начинает идти с момента, как он вырос.
16. Издали (> 32 блоков) стадо не бродит, но курицы несут яйца, детёныши растут, овцы едят траву (у «Есть траву» нет условия
    на `despawnCounter`). В радиусе тика — ASP-16.
17. Добыча падает в момент смертельного удара, тело ещё секунду лежит набок. Подобрать можно сразу через 10 тиков.
18. Попугай с соседнего дерева перелетает к стаду коров и вьётся над ними. Когда рядом зомби, иногда «рычит» его голосом.
19. Розовая овца — редкость: примерно 1 на 600.
20. Ведро молока можно выпить при полном здоровье, оно ничего не делает и возвращает ведро.
21. Ножницы по острижённой овце не тратятся и рукой не машут.

## 9. Чего нет в исходнике / не ясно

1. **`forcedAge`** — декомпиляция зеркала показывает `k = i − i`, то есть всегда 0. По смыслу (и по памяти о коде Mojang)
   должно быть `новый − старый` [не проверено]. Проверить в mcsrc (`AgeableMob.ageUp`). Влияет только на перезарядку
   детёныша, выращенного кормом (P2).
2. **Точные скорости в игре** зависят от навигации: срезание углов, торможение у узлов, прыжки на ступеньки. Числа §2.2 —
   установившийся ход по прямой. Скорость ходьбы по пути — эталон ASP-16.
3. **Свет при генерации.** У нас нет небесного света (ASP-14). Для спауна при генерации условие «свет ≥ 9» на поверхности
   в ванили выполняется всегда, кроме глубоких навесов. Предлагаю считать его истинным для клеток на карте высот, пока
   нет света [вывод].
4. **Цвета шерсти** в ванили — 16. Мы берём 6 природных; без красителей остальные недостижимы.
5. **Скорость в воздухе у попугая 1.7 б/с** — вывод из общего `getOffGroundSpeed = 0.02` [расчёт]. Ощущение «медленного
   порхания» сверить человеком (в ванили, если есть возможность).
6. **Где жить попугаю** — в данных ванили ответа нет. Это наше решение (§17).
7. Крошки еды у рта животных в 1.21.1 не показываются, звука поедания корма у фермерских нет [src: `AnimalEntity.eat`
   только уменьшает стопку]. Звук есть только у попугая (`parrot.eat`).

## 10. Сценарий проверки человеком

Подготовка: новый мир, режим выживания, время — день. Отладочные клавиши: «дать предмет», «ускорить время ×20»,
«показать коробки сущностей» (ASP-09 отладка, ASP-16).

1. **Найти стадо.** Иду по равнине или лесу 1–2 минуты.
   Ожидаю: группы ровно по 4 животных одного вида (свиньи, коровы, овцы или куры), группа на ~10 кусков. Животные стоят,
   раз в ~6 с одно уходит на 5–10 блоков и предпочитает траву. Головы крутятся по сторонам. В радиусе 6 блоков иногда
   смотрят на меня. Каждое животное подаёт голос в среднем раз в 8 с, шаги тихие. Коровы заметно медленнее свиней и кур.
2. **Дальность.** Отхожу на 40 блоков и смотрю издали.
   Ожидаю: через ~5 с стадо перестаёт бродить, овцы изредка опускают головы.
3. **Приманка (куры, семена).** Ломаю траву до семян (~1 на 8 травинок), беру семена в руку в 8–10 блоках от кур.
   Ожидаю: куры поворачиваются и идут ко мне, останавливаются в ~2.5 блока, смотрят. Отхожу шагом — отстают, но идут.
   Присел в 9 блоках — не замечают, подошёл на 7 — пошли. Переключил слот — встали. Сразу вернул семена — 5 с не идут.
   **Приманка пшеницей** (коровы, овцы) — так же, когда будет пшеница (§16), или через «дать предмет: пшеница».
   Ожидаю: корова идёт ~2.7 б/с, отстаёт от меня почти вдвое. Свинья с морковью (с зомби или «дать») почти не отстаёт.
4. **Размножение.** Кормлю двух кур по семечку.
   Ожидаю: над каждой вспышка сердечек, потом редкие сердечки. Куры сходятся, через ~3 с рядом — цыплёнок с крупной
   головой, пищит выше. Он ходит за курицей. Третье семечко той же курице не берётся (стопка не уменьшается) 5 минут.
   Кормлю цыплёнка — зелёные искры, он чуть подрос по счётчику (видно в отладке: −24000 → −21600).
5. **Удар.** Бью свинью рукой.
   Ожидаю: красная вспышка, визг, отлёт ~3 блока. Свинья мечется в случайные стороны 2–4 с быстрее обычного и
   успокаивается. Бью корову — она уносится очень быстро.
6. **Убить и пожарить.** Добиваю свинью (рукой — 10 ударов полной силы, железным мечом — 2).
   Ожидаю: в момент последнего удара — звук смерти, выпадает 1–3 сырой свинины, тело заваливается набок ~0.7 с и через 1 с
   исчезает облачком. Корова — 1–3 говядины и 0–2 кожи. Курица — 1 сырая курица и 0–2 пера. Детёныш — ничего.
   Кладу 3 сырой свинины в печь с углём.
   Ожидаю: по 10 с на штуку → 3 жареной свинины.
   Получаю урон до 12 HP (команда «урон 8») и ем жареную свинину.
   Ожидаю: через 1.6 с — 20 HP. Сырую при 20 HP съесть нельзя.
7. **Остричь овцу.** Делаю ножницы (2 слитка), ПКМ по белой овце.
   Ожидаю: щелчок ножниц, 1–3 белой шерсти, слегка разлетевшихся. Овца без шерсти: тоньше, видна «кожа». Ножницы −1.
   Повторный ПКМ — ничего, рука не машет. Жду у овцы на траве (×20 времени).
   Ожидаю: раз в ~1–2 мин овца опускает голову на 2 с и «жуёт». Под ней дёрн становится землёй (или пропадает травинка),
   шерсть возвращается мгновенно. Ломаю шерсть рукой — 1.2 с, ножницами — 0.25 с.
8. **Курица.** Сталкиваю курицу с обрыва в 10 блоков.
   Ожидаю: машет крыльями, планирует ~4.5 с, урона нет. Свинья с того же обрыва получает урон. Жду 10 мин (×20 — 30 с):
   курица роняет яйцо со звуком «плоп», яйца стакаются по 16.
9. **Корова и ведро.** ПКМ пустым ведром по корове.
   Ожидаю: звук доения, в руке ведро молока (из стопки 3 вёдер — 2 пустых и молоко в инвентаре). По телёнку — ничего.
   Пью молоко — 1.6 с, вернулось пустое ведро.
10. **Цвета.** Осматриваю ~50 овец.
    Ожидаю: ~41 белая, по 2–3 чёрных, серых, светло-серых, 1–2 коричневых. Свожу чёрную и белую — ягнёнок серый.
11. **Попугай** (если берём). Иду по лиственному лесу.
    Ожидаю: изредка попугаи по 1–2 на кронах. Медленно перепархивают с дерева на дерево, машут крыльями, в полёте ноги
    поджаты. Без пути плавно опускаются. Подлетают к коровам рядом. Удар — улетает, роняет 1–2 пера.

## 11. Что нужно от движка и от ASP-16

От ASP-16 (общий фундамент; коды движка назначит главный агент):
- тело моба: AABB, физика `travel` с гравитацией и трением, шаг 0.6, прыжок 0.42, урон и отбрасывание как у игрока
  (ASP-12 `Health`, `Body`), `hurtTime`, смерть (`deathTime` 20, удаление, облачко), падение и урон от него с флагом
  «неуязвим к падению»;
- флаги на уровне тела: `slow_fall` (×0.6 к падающей скорости после `travel`), `flutter` (вертикальное трение 0.91, ноги по
  |Δxyz|), `no_gravity` (полёт);
- селектор целей с приоритетами, управлениями MOVE/LOOK/JUMP, проходом раз в 2 тика по `age + id` и «каждый тик»;
  `despawnCounter` и сброс в 32 блоках;
- управление движением (`MoveControl`, прыжок на ступеньку), взглядом (`LookControl`), телом (`BodyControl`), полётом
  (`FlightMoveControl`);
- навигация по суше и для птиц, штрафы клеток (вода, огонь, кактус); выбор случайных целей (`NoPenaltyTargeting`,
  `FuzzyTargeting`, `AboveGroundTargeting`, `NoPenaltySolidTargeting`) с весом клетки (трава 10, иначе яркость − 0.5);
- спаун при генерации куска (группы, 4 попытки, зажим в кусок) и периодический (400 тиков, предел); пометка куска
  «заселён», чтобы не заселять дважды;
- рендер моделей из кубоидов: шарниры, порядок вращений, раздутие, UV-раскладка, тонировка слоя (шерсть), второй проход
  поверх (слой шерсти); детёныш через сдвиг головы и ×0.5 тела; тень; дальность по средней стороне коробки; красная вспышка;
  интерполяция yaw тела и головы;
- луч по сущностям и ПКМ по сущности (`interact` → результат PASS / CONSUME / SUCCESS, взмах руки), удар по сущности
  (ASP-12 §6);
- ГСЧ сущности и мировой ГСЧ (детерминированный, E12) — для цвета овцы, дропа, таймеров.

От движка (E-коды `../checklist.md`):
- **E1:** овца меняет блоки (трава → земля, растение → воздух), синхронная перестройка меша (как ломание). Событие
  «блок сломан» для частиц и звука без дропа.
- **E2:** запросы формы и типа блока для физики и путей мобов; предикат «блок травы» = `is_grass(b) || b == SNOWY_GRASS`
  (у нас `is_grass` снежную траву не включает!); «растение трава» = `TALL_GRASS` (17); «листва или бревно» для попугая.
- **E3:** фаза сущностей в тике.
- **E4:** мобы — новый вид сущности рядом с предметами и падающими блоками. Тик в квадрате 8 кусков, как у предметов.
- **E7:** иконки новых предметов. Отдельного UI нет.
- **E8:** ресурсы — 5 текстур мобов + слой шерсти (64×32, попугай 32×32 × 5 окрасов); спрайты: 4 сырых + 4 жареных мяса,
  перо, яйцо, кожа (уже есть в плане), ведро молока; блоки шерсти 6 цветов; звуки §7.1.
- **E10:** позиционные звуки; частицы: сердечко, зелёная искра, облачко смерти, крошки ломания (ест траву), крошки предмета
  (яйцо).
- **E11:** яркость моделей мобов — как у предметов (ASP-07 §8.5); свет для спауна (§9.3).
- **E12:** ГСЧ; отрастание травы на земле после овец — случайные тики (ASP-06 §1.5).
- Генератор (`gen.rs`, только читать): спауну нужен биом колонки. Сейчас `Biome` и `Gen::column` закрыты внутри
  `gen.rs` → нужна открытая функция «биом в (x, z)» (решение владельца генератора).

Предлагаемая раскладка в нашей архитектуре: данные мобов — `const`-таблицы Rust рядом с `registry.rs` (как блоки ASP-06).
Поведение — `mobs/` в Rust: тик, цели, взаимодействия; эталоны через `cargo test`. JS получает для отрисовки только
снимок: вид, позиция, yaw тела и головы, pitch, фаза и скорость ног, флаги (детёныш, острижена, цвет, вариант), таймеры
анимаций (`eat`, `flap`, `dev`), `hurt_time`, `death_time`.

            if self.age < 0 { self.age += 1; } else if self.age > 0 { self.age -= 1; }
        }
        if self.age != 0 { self.love = 0; }
        if self.love > 0 {
            self.love -= 1;
            return self.love % 10 == 0;
        }
        false
    }

    pub fn grow_up(&mut self, secs: i32, forced: bool) {
        let old = self.age;
        let new = (old + secs * 20).min(0);
        self.age = new;
        if forced {
            self.forced_age += new - old; // §3.3 п. 5 — проверить по mcsrc
            if self.happy == 0 { self.happy = 40; }
        }
        if self.age == 0 { self.age = self.forced_age; }
    }
}

pub enum Interact { Pass, Consume, Success }

/// ПКМ по животному предметом `held` (стопка уже выбрана по руке, ASP-05). Побочные эффекты — в `fx`.
pub fn interact(def: &MobDef, a: &mut Animal, ex: &mut Extra, held: &mut ItemStack, fx: &mut Vec<MobFx>, rng: &mut Rng) -> Interact {
    match ex {
        Extra::Sheep { color, sheared, .. } if held.item == SHEARS => {
            if *sheared || a.is_baby() { return Interact::Consume; }
            *sheared = true;
            fx.push(MobFx::Sound(S_SHEEP_SHEAR));
            for _ in 0..1 + rng.below(3) { fx.push(MobFx::DropWool { color: *color }); } // +1 по высоте, добавка к скорости §5.1
            fx.push(MobFx::DamageHeld(1));
            return Interact::Success;
        }
        _ => {}
    }
    if def.kind == MobKind::Cow && held.item == BUCKET && !a.is_baby() {
        fx.push(MobFx::PlayerSound(S_COW_MILK));
        fx.push(MobFx::ExchangeHeld(MILK_BUCKET)); // как ведро воды: из стопки одно, остальное в инвентарь или на землю
        return Interact::Success;
    }
    if !def.breed_food.is_empty() && def.breed_food.contains(&held.item) {
        if a.age == 0 && a.love <= 0 {
            held.count -= 1;
            a.love = LOVE_TICKS;
            fx.push(MobFx::HeartBurst);
            return Interact::Success;
        }
        if a.is_baby() {
            held.count -= 1;
            a.grow_up(Animal::to_grow_up_age(-a.age), true);
            return Interact::Success;
        }
    }
    Interact::Pass
}

/// Шаг 7a/7b §1: крылья и медленное падение. Вызывать после travel.
pub fn tick_wings(w: &mut Wings, on_ground: bool, riding: bool, vel_y: &mut f64) {
    w.prev_flap = w.flap;
    w.prev_dev = w.dev;
    let k: f32 = if !on_ground && !riding { 4.0 } else { -1.0 }; // у курицы riding всегда false
    w.dev = (w.dev + k * 0.3).clamp(0.0, 1.0);
    if !on_ground && w.speed < 1.0 { w.speed = 1.0; }
    w.speed *= 0.9;
    if !on_ground && *vel_y < 0.0 { *vel_y *= 0.6; }
    w.flap += w.speed * 2.0;
}

/// Угол крыла для кадра (рад), α — доля тика.
pub fn wing_roll(w: &Wings, alpha: f32) -> f32 {
    let f = w.prev_flap + (w.flap - w.prev_flap) * alpha;
    let d = w.prev_dev + (w.dev - w.prev_dev) * alpha;
    (f.sin() + 1.0) * d
}

/// Яйцо (§5.2). true — уронить яйцо и сыграть «плоп».
pub fn tick_egg(egg: &mut i32, adult: bool, alive: bool, rng: &mut Rng) -> bool {
    if !(alive && adult) { return false; } // у цыплёнка таймер стоит
    *egg -= 1;
    if *egg <= 0 { *egg = 6000 + rng.below(6000) as i32; return true; }
    false
}

pub fn roll_wool(rng: &mut Rng) -> Wool {
    match rng.below(100) {
        0..=4 => Wool::Black,
        5..=9 => Wool::Gray,
        10..=14 => Wool::LightGray,
        15..=17 => Wool::Brown,
        _ => if rng.below(500) == 0 { Wool::Pink } else { Wool::White },
    }
}

/// Цвет ягнёнка: «рецепт красителей» из двух цветов, иначе случайный родитель.
pub fn child_wool(a: Wool, b: Wool, rng: &mut Rng) -> Wool {
    use Wool::*;
    match (a, b) {
        (Black, White) | (White, Black) => Gray,
        (Gray, White) | (White, Gray) => LightGray,
        _ => if rng.below(2) == 0 { a } else { b },
    }
}

/// Поедание травы: на старте в тике T0 eat = 40, первый шаг в том же тике (→ 39);
/// блок меняется при eat == 5, то есть в T0 + 34 (§3.2, §12 п. 8). Тот же eat — таймер головы для рендера (§5.1).
pub enum EatResult { Nothing, AtePlant(BlockPos), AteGrass(BlockPos) }
pub fn eat_grass_step(eat: &mut u8, feet: BlockPos, w: &impl MobWorld) -> EatResult {
    if *eat == 0 { return EatResult::Nothing; }
    *eat -= 1;
    if *eat != 5 { return EatResult::Nothing; }
    if w.block(feet) == TALL_GRASS { return EatResult::AtePlant(feet); }
    let below = feet.down();
    if w.is_grass_block(below) { EatResult::AteGrass(below) } else { EatResult::Nothing }
}

/// Дроп при смерти (§6.1). on_fire — для будущей лавы.
pub fn death_loot(def: &MobDef, a: &Animal, ex: &Extra, on_fire: bool, rng: &mut Rng, out: &mut Vec<ItemStack>) {
    if a.is_baby() { return; }
    for d in def.loot {
        match *d {
            MobDrop::Item { raw, cooked, min, max } => {
                let n = min + rng.below((max - min + 1) as u32) as u8;
                if n > 0 {
                    let item = if on_fire { cooked.unwrap_or(raw) } else { raw };
                    out.push(ItemStack::new(item, n));
                }
            }
            MobDrop::SheepWool => {
                if let Extra::Sheep { color, sheared: false, .. } = ex { out.push(ItemStack::new(wool_item(*color), 1)); }
            }
        }
    }
}
