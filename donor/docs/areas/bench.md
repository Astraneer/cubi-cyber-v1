# Памятка bench — эталонный маршрут, сравнение сборок, метрики вида

Цель (Q16): числа, которым можно верить. Две прогонки одной сборки в тишине расходятся меньше чем на 5 %; замедление
сборки ловится сравнением; «тени дёргаются» — число. Скорость меряется на видеокарте ноутбука (RTX 3050, холст
3440×1440, Chrome + ANGLE D3D11), не в SwiftShader.

## Что где

| файл | что |
|---|---|
| `web/game/route.js` | в странице: маршрут `?route=all` (отрезки `SEGS`) и кадры для метрик вида `?look=<сцена>` (виртуальное время, readPixels, мерцание) |
| `web/game/bench.js` | крючок: при `?route` / `?look` отдаёт управление `route.js` |
| `web/engine/params.js` | крючок: `route` и `look` — проверки без рук (авто-качество и темп выкл.) |
| `web/render/shadows.js` | крючки только для проверок: `?shsnap=0` (без привязки), `?shsnap=fix` (привязка, которая работает), `__benchShift` (сдвиг каскадов при неподвижной камере) |
| `perf/bench/route.mjs` | оркестратор: `run`, `look`, `compare A B`, `page`, `ref`, `list`, `status`; итоги, сравнение, попиксельное сравнение |
| `perf/bench/lib.mjs` | замок `.bench.lock`, тишина, Chrome по CDP, статика, PNG без зависимостей, статистика кадров |
| `perf/bench/page.mjs` | HTML-страница `voxel-wt/_bench/index.html` |
| `perf/bench/quiet.ps1` | чужая нагрузка за ~1 с: процессор (кроме своего Chrome), 3D дискретной видеокарты, топ процессов |
| `tools/ci/bench_wait.sh` | ожидание замка в `tools/check.sh` и `build.sh` |

Замеры всех сборок — общая папка `voxel-wt/_bench/<сборка>/<сеанс>/` (вне git): `route-<пресет>-<n>.json`,
`summary.json`, `look/<сцена>.{png,jpg,json}`, `-heat.png`; `journal.jsonl` — строка на пресет и сеанс; `ref.txt` — эталон.

## Как запустить

```
node perf/bench/route.mjs run --tag <имя>          # маршрут × «По умолчанию», «Тяжелее» × 2 повтора + вид, ~16 мин
node perf/bench/route.mjs compare <база> <новая>   # что лучше / хуже и где; код выхода 1 — стало хуже
node perf/bench/route.mjs page <база> <новая> …    # voxel-wt/_bench/index.html
```

Ключи `run`: `--root <папка web>` (другая сборка; нужен `web/game/route.js`), `--presets`, `--reps`, `--only отрезки`,
`--no-look`, `--scenes`, `--q "ключ=знач"` (добавить к адресу: `routeslow=2` — нарочно медленнее на 2 мс CPU,
`shsnap=fix`), `--wait мин` (сколько ждать тишины), `--note`. Без `--tag` имя — короткий коммит (+ «+» при правках).

## Маршрут (`SEGS` в route.js; менять осознанно — старые прогоны с новыми не сравнить)

| отрезок | где | с | что делает |
|---|---|---|---|
| forest | лес (−400, 384) | 12 | облёт r 14 на 12 над землёй, 15°/с; 13 мобов у центра |
| crossroads | витрина машин (−5.5, 73.6, 12→−6) | 12 | вдоль галереи 1,5 блока/с |
| mountain | вершина (−416, 140, 992) | 12 | поворот ±30° (дальний LOD) |
| water | берег (128, 72, −224) | 12 | вдоль берега 2,5 блока/с |
| flight | от (296, 104) на восток | 15 | 40 блоков/с, 35 над рельефом (подгрузка) |
| build | лес (−400, 400) | 12 | стена 6×4: блок каждые 0,15 с, круг ставит, круг ломает (`world_edit`) |
| night | Перекрёсток ночью (0.5, 40.5) | 10 | к Маяку 1 блок/с, 6 факелов |

На отрезке: подготовка → ожидание догрузки (не меряется, тики стоят, не дольше 40 с) → разгон 1,5 с по тому же пути →
замер. Путь — функция времени отрезка: в любой сборке камера проходит те же места за то же время.
Пресеты: «По умолчанию» (MSAA, тени, умолчания графики), «Тяжелее» (`view=512&near=40`). Темп 60 к/с (`?cap=60`: как у
пользователя — 120 Гц, делитель 2), авто-качество выключено. `--nocap` — без предела: интервал = цена, но забор очереди
(кадр N−2) делает пары 3 / 20 мс, и интервалы двугорбые.

## Итог и сравнение

- Плавность (интервалы): «вовремя» — доля интервалов ≤ 20,8 мс (кадр попал в слот 16,7; середина до пропуска 25 мс),
  рывков > 25 и > 50 мс, средний интервал, p95/p99, «1 % худших».
- Цена кадра: GPU по таймерам (p50/p95) и CPU кадра (p50/p95) — ловят замедление, которое темп 60 ещё прячет.
- По отрезкам; GPU по проходам, CPU по подсистемам (самописец Q15: blocks, mobs, models, …), счётчики (вызовы, мобы).
- Причины рывков — метки самописца `web/engine/flight.js` (cause, для gpu/js — и где: `gpu·opaque`); без него — `prof:*`.
- Повторяемость: (макс − мин) / среднее по повторам для среднего интервала, p95, доли «вовремя», GPU p50 и CPU p50;
  ворота < 5 %. Счёт рывков (единицы на прогон) в ворота не входит — он сравнивается с порогом «> 5 % и не меньше 3».
- Сравнение: «хуже/лучше» — только если разница > 5 % и > 1,5 разброса повторов любой из сборок; иначе «≈».

## Тишина и замок

- `.bench.lock` в общем `.git` (`voxel-rust-demo/.git/.bench.lock`): JSON {pid, who, since, until}, обновляется раз в
  10 с; старше 60 с — мёртвый. `tools/check.sh` (в начале и перед браузерными шагами) и `build.sh` ждут его (не дольше
  40 мин). Заодно держится замок `perf/stand.mjs` (tmp/voxel-stand.lock).
- Перед прогоном — три замера подряд: чужой процессор < 15 % машины, чужая дискретная видеокарта < 10 %, нет
  браузерной проверки check.sh, видеокарта ≤ 75 °C (ждём до `--wait` мин, потом прогон помечается).
- Во время прогона — замер раз в ~4 с + журнал нагрузки `voxel-wt/_loadlog` (Q15): чужой процессор ≥ 20 % или
  видеокарта ≥ 15 % в двух замерах, cargo / Chrome пользователя ≥ 5 % в журнале — прогон «грязный» и в итог не идёт,
  если есть чистые.

## Метрики вида

- `?look=<сцена>`: виртуальное время (кадр = ровно 1/60 с для игры, шейдеров и тиков; пока мир грузится — стоит;
  сдвигается только после снятого кадра — пропуск rAF темпом его не двигает), съёмка с кадра, кратного 6 (фаза каскадов
  теней), через 1,5 с после догрузки (растворение плиток), как по F1 — без руки и рамки блока (рука покачивается сама и
  давала больше половины «мерцания» листвы и воды). Три съёмки одной сборки дают одно число (тени — три раза одно и то
  же до тысячной); витрина плавает на ~1 % (кабели машин анимируются по настоящему времени).
- Мерцание: доля пикселей (‰ пикселе-кадров), чья яркость за два кадра подряд качнулась туда и обратно больше чем на
  12/255; карта мерцания и сетка 16×8. Ровное движение края в одну сторону не считается.
- Сцены (`SCENES` в route.mjs): shadows (камера стоит, каскады едут 0,5 блока/с — как при ходьбе), walk, leaves,
  water, far (рябь дальнего LOD, поворот 1°/с), crossroads, night.
- Попиксельное сравнение кадра 0 с эталоном (`ref`): пиксель изменился, если канал разошёлся > 16/255; маска — PNG.

## Грабли

- Второй `Page.navigate` в том же Chrome после выдачи результата `?look` (десятки МБ) зависал — сцена в свежем Chrome.
- Импорт `route.mjs` из другого скрипта запускал прогон — команды только при запуске файла (`MAIN`).
- Привязка каскадов к текселям в render/shadows.js не работает: `lview` смотрит из точки над центром каскада, центр в
  его координатах всегда (0, 0) — `Math.round` ничего не привязывает (`?shsnap=0` = как есть). `?shsnap=fix` — поворот
  без переноса, тогда привязка держит тени: мерцание теней при ходьбе 0,205 → 0,009 ‰ (в 23 раза), вся поляна в движении
  1,21 → 0,91 ‰.
