# Локальный авторитетный сервер

Запуск: `source tools/env.sh`, затем
`cargo run -p server -- --data .local/server`.
WebSocket по умолчанию: `127.0.0.1:25565`, UDP: `127.0.0.1:25566`.
Параметры `--ws 127.0.0.1:0 --udp 127.0.0.1:0` выбирают свободные порты;
`--run-millis 1000` ограничивает длительность дымового запуска.
Файл готовности содержит только публичные адреса слушателей.

`owner.identity` — приватный двоичный файл локального входа; его содержимое
не печатается. Обычный игрок получает credential один раз, затем использует
стабильные ID, имя и credential. На диске сохраняется только хеш credential.
`generation.key` хранится отдельно и отсутствует в сетевых сообщениях, снимках
мира и диагностике. Потерянный ключ существующего мира нужно восстановить из
приватной резервной копии вместе с `owner.identity`.

Миром владеет один поток. Порядок фаз: до двух доверенных транзакций систем,
ограниченная очередь сообщений, результаты/отправка генерации, общая физика
игроков и по одному действию на игрока, затем одна запись WAL. Ответ Accepted,
подтверждение движения, трансформации и страницы выходят только после fsync.
Снимок захватывает Arc страниц; разворачивание, кодирование, контрольные суммы,
fsync и атомарная замена выполняются потоком сохранения. Периодические снимки
ограничивают WAL. При ошибке хранения публикация прекращается.

Ввод имеет sequence и `target_tick`: ненулевой target_tick задаёт тик авторитета
для предсказания, очередь ограничена 64 будущими тиками. Ноль означает ближайший
тик с начальным буфером перестановки 150 мс. Без ввода идёт нейтральная физика;
Unknown блокирует движение без потребления sequence. Пакет Prediction содержит
только публичное точное состояние физики; приватные права и инвентарь исключены.
`client::network::Connection` восстанавливает это состояние, повторяет оставшийся
ввод с ограниченным бюджетом и отдаёт подтверждённые страницы владельцу сцены.
Подключение этого модуля к View пока требует отдельного шага.

ActionId сохраняется в ограниченном окне дедупликации в одной записи с изменением
мира. Переполнение очереди даёт повторяемую ошибку Error(RateLimited), а не
окончательный неподтверждённый отказ. После переподключения Welcome.next_action
указывает первый незавершённый ID: клиент повторяет исходное действие.
Сроки задержки установки/добычи переживают переподключение и перезапуск.
Команды владельца: `/gamemode`, `/tp`, `/ban`, `/unban`, `/op`, `/deop`,
`/rollback`, `/space_move`, `/give`; командная оболочка не вызывается.
Rollback ограничен последними 256 доступными транзакциями только клеток,
проверяет текущее состояние и явно отклоняет смешанные операции.

Собственный инвентарь передаётся только владельцу. Survival PlaceOwned проверяет
ревизию, выбранный слот и точный стек; расходует один предмет вместе с изменением
клетки в одной записи WAL. Stale/Unknown ничего не расходуют; повтор ActionId не
расходует предмет повторно. SelectSlot и остальные действия запускаются по ID.
Добыча использует только собственный инструмент, изнашивает его и создаёт один
долговечный DropBundle в той же транзакции. Смена предмета отменяет добычу;
поддельный tool ID отклоняется. RNG выпадения задан приватным ключом мира,
игроком и ActionId. `/give` — явная команда администратора; новый инвентарь пуст.
Физика/подбор item entities и полные окна crafting/container подключаются отдельно.
`queue_transaction` принимает операции доверенных серверных систем, а не
произвольные клиентские транзакции.

Истории страниц персональные: руда заменяется камнем до доказанной видимости;
Unknown закрывает луч. Дельта строится только от подтверждённой сохранённой базы,
иначе передаётся полный снимок с палитрой. Правка заслоняющего блока обновляет
видимость даже у страницы без изменения её исходной версии. AOI переносимых
решёток учитывает quaternion transform; геометрия и окончательная трансформация
передаются отдельно. Руды другой решётки консервативно скрыты до общей физики и
видимости нескольких пространств. Дальние сводки построены по настоящим клеткам;
грубая сводка 4³ не заменяет адаптивный LOD и не сохраняет каждое узкое отверстие.

Транспорты отклоняют адреса вне loopback. UDP имеет направленные BLAKE3 MAC,
ограниченную фрагментацию, сборку и повторную отправку; начальный обмен локальный
и открытый. Для удалённого production нужны зашифрованное установление соединения,
TLS для WebSocket, сертификаты и хранение секретов. Это пока не реализовано.

Проверки: `cargo test -p net -p save -p server --locked` и
`cargo test -p client --test network_owner --locked`.
Есть настоящие WebSocket/UDP, 2 и 32 бота с задержкой 75±20 мс, потерями 2 % и
перестановкой, общая физика, предсказание/откат, скрытые руды, права, потеря базы,
транзакция 10 000 клеток и принудительное завершение внешнего процесса сразу после
Accepted. Счётчики работы и трафика — доказательства; время облака справочное.
