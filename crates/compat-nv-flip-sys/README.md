# NVIDIA FLIP: CPU-метрика без загрузчиков изображений

Адаптация опубликованного nv-flip-sys 0.1.0 из crates.io. Исходный архив
проверен по SHA256; происхождение и хеш каждого файла — в PROVENANCE.json.
Код NVIDIA сохраняет BSD-3-Clause и исходные copyright notices; FFI-обвязка
upstream предоставлена под MIT OR Apache-2.0 OR Zlib. Это не новая метрика и
не замена FLIP упрощённой разницей пикселей.

Исходный tensor.h безусловно включал TinyEXR со встроенным miniz под Unlicense,
которой нет в разрешённом списке ТЗ. Здесь исключены только необязательные методы
загрузки/сохранения файлов, их include и конструктор изображения из имени файла.
TinyEXR, miniz, STB и CUDA сюда не копируются и не компилируются. Численные
операции цвета, свёрток, признаков и FLIP не изменены. Изображения передаются
из Rust как RGB-буферы; PNG декодируется разрешённым отдельным Rust-крейтом.

Сборка требует C++17. Это зависимость только нативных тестов, не WASM-клиента.
Права на тестовые картинки сторонних репозиториев не используются: эталоны
создаются из сцены нашего движка и разрешённого донорского атласа.
