# Адаптер классификации идентификаторов

Это новый код Cubi, а не скопированная реализация `unicode-ident` и не изменение её лицензии.
Имя пакета и версия нужны только для `[patch.crates-io]` существующих потребителей.

Две функции делегируются публичному API `unicode-xid = 0.2.6`, опубликованному под
MIT OR Apache-2.0. Проверены `Cargo.toml`, `COPYRIGHT` и заголовки исходников/таблиц
архива crates.io; SHA256 архива:
`ebc1c04c71510c7f702b52b7c350734c9ff1295c464a03335b00bb84fc54f853`.
Таблицы исходного `unicode-ident` сюда не копировались.

Область совместимости: `is_xid_start`, `is_xid_continue`, `UNICODE_VERSION`.
Используется Unicode **16.0.0**, соответствующий закреплённому Rust 1.90.0;
исходный `unicode-ident 1.0.27` использует Unicode **18.0.0**. Идентификаторы,
впервые добавленные в Unicode 17/18, намеренно не принимаются этим адаптером.
Это не изменение строк локализации или игровых ID. При обновлении toolchain
необходимо отдельно согласованно обновить классификатор и его эталоны.
