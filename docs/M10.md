# M10: атмосфера в разработке

`render::atmosphere` вычисляет LUT пропускания и sky-view из Rayleigh, Mie и озонового поглощения вокруг сферической планеты. Это собственные Rust/WGSL; код рендера и шейдеры донора не использованы. Расстояния — километры, высоты экспоненциальных профилей — 8 и 1,2 км.

По умолчанию пропускание имеет размер 256×64 и 64 шага интегрирования; sky-view — 192×108 и 48 шагов. Формат — `RGBA16Float`, два compute-конвейера готовятся при загрузке. Изменение солнца/высоты пересчитывает только sky-view, статичный кадр — ничего. Записи параметров и шаги интегрирования имеют явные бюджеты; отказ сохраняет ожидающую работу. После отмены уже закодированного, но не отправленного обновления владелец вызывает `invalidate`.

`TerrainGpu::attach_atmosphere` подключает LUT при загрузке к общему MSAA 4× / HDR / final transfer. Направление берётся из обратной матрицы камеры; её изменение добавляет 64 байта загрузки. Изменение только LUT не загружает камеру или геометрию. Владелец выполняет `encode_update` до terrain и инвалидирует сохранённый план кадра при изменении сияния. Эталон M2 сохраняет исходный режим неба.

| Настоящий software Vulkan | Результат |
|---|---|
| Пропускание против независимого f64 / 4096 шагов | 242 RGB-отсчёта, максимальная абсолютная ошибка 0,00058784 |
| Уменьшенная тестовая конфигурация | 204 800 шагов при старте; 73 728 при смене солнца; 0 в статике |
| Солнце за планетой | Просочившегося прямого рассеянного света 0 |
| Общий terrain HDR, 12 513 пикселей | Яркость при взгляде вверх 5 059 696, вниз 285 218 |
| Изменение только LUT | 0 байт камеры и геометрии; ночное изображение без солнечного света |

```sh
source tools/env.sh
VK_ICD_FILENAMES="$PWD/.local/mesa/lvp-local.json" cargo test --locked -p render --test atmosphere -- --nocapture
VK_ICD_FILENAMES="$PWD/.local/mesa/lvp-local.json" cargo test --locked -p render --test terrain_gpu -- --nocapture
```

Это ограниченное однократное рассеяние, а не завершённая модель Hillaire или весь M10. Остаются многократное рассеяние, воздушная перспектива, облака, физическая вода, светила, emission/bloom, экспозиция, пробы GI/H6, labPBR, управление клиента, эталоны сцен и бюджеты по GPU-проходам. Alpha sky-view хранит диагностическое среднее пропускание и не заменяет RGB-пропускание при будущей композиции поверхностей.
