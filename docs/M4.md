# M4: свет и стабильные тени

Native и browser подключают authoritative LIGHT, GPU-объёмы и кэш теней в общий View. Базовые контракты и компонентные GPU-проверки пройдены; полная приёмка H5 на продуктовом маршруте ещё не завершена. Энергия и ответственность — [LIGHTING.md](LIGHTING.md).

## Выполненные проверки

`cargo test --locked -p world --test lighting` проверяет CPU RGB/skylight независимой BFS: удаление источника, крыша/стены, граница страниц и пространств, Unknown и ограниченные очереди. Эти 13 тестов существовали до GPU-интеграции.

`VK_ICD_FILENAMES="$PWD/.local/mesa/lvp-local.json" cargo test --locked -p render --test shadows -- --nocapture --test-threads=1` запускает настоящий программный Vulkan: 8 проверок.

- Аналитический AABB-эталон: 336 точных отсчётов глубины коробки и отсутствие лишнего покрытия. Двенадцать статичных кадров: 0 shadow draw вместо 180 у полного обновления трёх каскадов. После локального переноса очищено 944 из 49 152 текселей; результат совпадает с полным перерисовыванием побитно. Статика и 20 субтексельных шагов дают нулевое мерцание.
- На 32 шагах ходьбы сетка пересекла 31 границу привязки; маска теней на неподвижных мировых получателях дала 0 ‰ дрожи при пороге H5 0,02 ‰. Независимые лучи против AABB подтвердили 547 затенённых и 15 375 освещённых пикселей. Реальный шаг солнца меняет тень, затем изображение стабилизируется. Чёрная/белая константа не проходит эталон видимости.
- Настоящее GPU-чтение светового буфера: изменение трёх отсчётов занимает 12 байт и сохраняет все остальные значения. Старое поколение, неверный порядок индексов и недостаточный бюджет отклоняются до записи.

Дополнительно проверены 4-байтовая живая ссылка overlay на базовый том и равномерный 4-байтовый свет модели. Fixed OwnerPatch-оболочка правки отбрасывает побитно ту же глубину тени, что финальный greedy-меш.

Шесть CPU-тестов проверяют стабильные матрицы, атомарную публикацию, локальные dirty-области, справедливость обслуживания и границы конфигурации. Два теста упаковки света проверяют все уровни и координаты рамки. Учёт аллокаций с положительным контролем подтверждает нулевую работу статичного CPU-кэша.

## До завершения этапа

`client/tests/lighting_gpu.rs` проверяет полный компонентный путь: initial 15 642 клетки / 47 952 Б загрузок, удаление факела 8044 клетки, статичный цикл — 0 клеток / 0 загрузок геометрии или света. Три теста также проверяют плавающий блок через Unknown и bootstrap больше очереди seed. Шесть чистых тестов проверяют dirty-рамки/квоты/FIFO.

Подключение View выполнено. Остались продуктовые эталоны освещённых леса, ночи и пещеры, ходьба/поворот через границы каскадов с листвой и анимированными моделями, сравнение полной стоимости cached/full-redraw. Программные проверки измеряют работу и корректность, не время на RTX.

## Выбранный продуктовый профиль и измерения

Runtime выбрал 2048²×3 для статического и отдельного combined depth:
96 MiB полезных depth-данных. Tier A 1024² — 24 MiB; доступный API 4096²
с combined — 384 MiB. Это размеры созданных Depth32Float descriptor,
а не измерение фактически занятой VRAM драйвера.

H5 повторён на разрешении 2048² с combined, но с тестовыми полуширинами
16/32/64 и depth_half_extent32 вместо продуктовых 32/128/512 и1024.
Проверка использует одну коробку и неподвижные приёмники в области24×24;
она не покрывает переход между каскадами, листву и живую модель.
32 шага камеры дали 32
ограниченных cascade updates, мерцание фиксированных приёмников 0‰,
независимо подтверждены 547 shadow и 15 375 sky samples. Изменение солнца
меняет результат; после сходимости — 0 draw/query/copy. Warm + walking +
sun всего 38 обновлений: 159 383 552 обработанных depth texel и
637 534 208 байт GPU static→combined copy (16 MiB на обновлённый слой).
Длительность на RTX этим software-Vulkan тестом не измерена.

`ShadowGpu` теперь имеет фиксированный query pool: kind1 static frustum,
kind2 static clear/depth, kind3 moving-model depth. Три обновлённых каскада
дали шесть настоящих положительных GPU-длительностей; статический кэш —
0 queries. `timing_source()` передаёт их FrameGpuCapture как shadows.
Copy-команды и собственные compute cull проходы dynamic caster пока не
входят в эту сумму; счётчики bytes/dispatches сохранены отдельно.

Обновление RGB8/confirmed LIGHT описано в `LIGHTING.md`: том 23 332 байта,
независимый header, alias 4 байта, uniform 8 байт при создании / 4 при
изменении. Пять client GPU-проверок включают нулевой LIGHT snapshot без
WorldChange, [231,17,255] без потери и отзыв при смене public cell_view.

Для authoritative mode добавлен отдельный `ingest_scene_cpu`: ограниченное
чтение журнала работает независимо от ожидания GPU и не имеет доступа к
Queue. Крупная LIGHT-транзакция (>1024 samples) инвалидирует полные тома
через метаданные изменённых страниц и halo, не обходит поштучно snapshot.
GPU затем читает актуальное World LIGHT с прежней проверкой сертификатов;
малые дельты сохраняют patch-путь. Отбросить dirty metadata без resident
можно в пределах 27 probes на квоту страницы, без расходования квоты
реальных загрузок. Диагностика ready отдельно показывает source, journal,
полные тома, aliases, instances и shadow cache; критерии готовности не
ослаблены. Тест проверяет 4096 changes → 1 metadata entry, CPU sample reads0
и uploads0, прежнее GPU-слово до публикации, затем точный HDR RGB8.


## Незакрытая экономия H5

Кэш статики действительно даёт 0 draw/dispatch/upload в неизменной сцене.
Однако это пока не доказательство ускорения вдвое всего продуктового
теневого графа. Любое изменение модели обновляет combined целиком во всех
трёх каскадах: 48 MiB GPU-copy на кадр при 2048². Локальная idle-анимация
игрока меняет позу даже без движения. Тест 2048² включает combined target,
но не живого model caster; отдельные model-тесты используют меньшие карты.
В текущую сумму timestamp не входят copy и compute самого model caster.

Перед полной приёмкой нужны локальный restore старого+нового следа моделей,
полное измерение shadow graph и actual default-параметры с контактными
тенями, каскадными переходами и alpha-cutout лесом. Это ограничение
производительности и покрытия проверки, а не подтверждённое ускорение2×.
