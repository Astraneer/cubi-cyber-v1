# Договоры систем

M0 не содержит транзакций мира или симуляции. Следующие договоры действуют уже сейчас.

| Система | Что истинно сразу | Что выполняется позже / граница |
|---|---|---|
| Импорт | Только белый список §2 из точного SHA; манифест содержит размеры, Git blob SHA-1 и SHA256. | `--verify` проверяет локальную копию без сети. Изменённый импорт не перезаписывается. |
| Счётчики | Логические операции учитываются явно; snapshot/reset не выделяют память. | Счётчики новых подсистем добавляются вместе с реализацией, не заменяются оценкой времени. |
| Самописец | Фиксированная ёмкость; новые записи вытесняют старые в определённом порядке. | Сериализация F8 вне горячего пути — будущий этап. |
| Аллокатор | Scope учитывает операции своего потока, включая realloc и zeroed; вложенные scopes запрещены. | Это измеритель, не запрет аллокаций драйвера; WASM workers требуют отдельных измерений. |
| Небо | Pipeline и MSAA attachment создаются до первого кадра; ресурсы размера меняются при resize. | GPU исполняет записанные команды; чтение пикселей только для запуска/тестов, не каждый кадр. |
| Запуск | Ошибка WebGPU показывается явно; WebGL fallback отсутствует. | Сервисы и процессы перезапускаются в каждой задаче; подготовленные файлы не означают живой процесс. |

Перед M1 для журнала, курсоров, версий и всех производных кэшей добавляется договор commit/асинхронного завершения по §4.3.
