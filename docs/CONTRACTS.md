# Договоры систем

Следующие договоры проверены для M0/M1. Показатели CPU/GPU в миллисекундах остаются отдельной проверкой на целевом железе.

| Система | Что истинно сразу | Что выполняется позже / граница |
|---|---|---|
| Импорт | Только белый список §2 из точного SHA; манифест содержит размеры, Git blob SHA-1 и SHA256. | `--verify` проверяет локальную копию без сети. Изменённый импорт не перезаписывается. |
| Счётчики | Логические операции учитываются явно; snapshot/reset не выделяют память. | Счётчики новых подсистем добавляются вместе с реализацией, не заменяются оценкой времени. |
| Самописец | Фиксированная ёмкость; новые записи вытесняют старые в определённом порядке. | Сериализация F8 вне горячего пути — будущий этап. |
| Аллокатор | Scope учитывает операции своего потока, включая realloc и zeroed; вложенные scopes запрещены. | Это измеритель, не запрет аллокаций драйвера; WASM workers требуют отдельных измерений. |
| Небо | Pipeline и MSAA attachment создаются до первого кадра; ресурсы размера меняются при resize. | GPU исполняет записанные команды; чтение пикселей только для запуска/тестов, не каждый кадр. |
| Запуск | Ошибка WebGPU показывается явно; WebGL fallback отсутствует. | Сервисы и процессы перезапускаются в каждой задаче; подготовленные файлы не означают живой процесс. |
| Мир | Все изменения клетки/компонента/света/пространства валидируются до применения и коммитятся атомарно. Клонируются только затронутые страницы; версии и шесть масок актуальны сразу. | Мешинг/сеть/свет/LOD/сохранение потребляют журнал по собственным курсорам. Сам `read` возвращает Known/Unknown и ничего не генерирует. |
| Журнал | Игровые события и порядок коммитов сохраняются; независимый курсор требует явного ack после успешной обработки. | Ограничения количества/байтов/возраста не скрываются: отставание даёт явный разрыв/снимок. Для будущего durable-save требуется отдельная политика подтверждения. |
| Снимки | Arc-снимок неизменяем; версии каналов отделяют геометрию от света и содержимого. Версии удалённых страниц сохраняются как tombstone против ABA. | Перед публикацией результата проверяются все версии входов, включая рамку соседних страниц. Устаревшее не публикуется. |
| Очереди | Количество, память, возраст и резерв ближних правок ограничены; coalescing применяется только к производным задачам. | Выдача по логическим cells/quads/bytes/rays. Истёкшее игровое событие возвращается владельцу с payload; отмена не означает разрешения потерять событие. |
| Генерация | Задача получает координаты/сид/ожидаемую версию; публичный пакет не содержит приватного генератора руд. | Native выполняет в ограниченном пуле; WASM — в настоящем Worker с SAB или transfer. Публикация результата — отдельная атомарная транзакция владельца мира. |
| Приватная генерация | Ключ 256 бит доступен только серверному `gen-authority`, не имеет Debug/Serialize и не попадает в сообщения публичных worker. | Сервер раскрывает данные только по правилам видимости M6. Legacy golden-tools — отдельный инструмент, не браузерная поставка. |
| Детерминизм | 128 последовательных транзакций дают одинаковые 64-битные хеши на каждом тике в native и настоящем WASM. Все четыре PROBE_REF совпадают. | Асинхронная доставка сама по себе не фиксирует симуляционный тик; публикации должны войти в сценарий/самописец как явные входы и применяться стабильной фазой. |
