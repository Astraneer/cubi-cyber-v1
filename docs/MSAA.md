# Выбор одного или четырёх отсчётов

`TerrainGpu::new` сохраняет умолчание 4×. Загрузчик может вызвать
`new_with_samples(..., 1 | 4)`; остальные значения отклоняются до создания
ресурсов. Выбор передаётся моделям сущностей/блоков, height tiles и точным
LOD-прокси через `TerrainGeometry.sample_count`, а атмосфере, небесным телам,
воде, дымке и облакам — через общий владелец графа. Настройка не может менять
только terrain, оставляя соседний проход с несовместимыми attachments.

В режиме 1× HDR color и resolved HDR ссылаются на одну текстуру; не создаётся
лишний MSAA-буфер и не задаётся запрещённый resolve target. Содержимое этого
общего буфера сохраняется перед постом. Вход и выход разных оптических проходов
остаются разными изображениями: обратной связи чтение/запись нет. Например,
полноразмерная пара дымки занимает 8 вместо 40 байт/пиксель. Число отсчётов
композиции и её лимиты учитывают выбранный режим.

WGSL-варианты подготавливаются при загрузке. У 1× обычные texture/depth inputs
и один отсчёт в Hi-Z/opaque resolve; четырёхугольники и четыре соседа билинейной
фильтрации сохраняются. A2C включён при 4×. Отдельные метки портов при 1×
используют alpha blending; цвет непрозрачных тел с alpha=1 сохраняется.
MSAA по-прежнему не выключается автоматическим качеством.

Проверены настоящим lavapipe:

- 1× terrain: Hi-Z и рендер без отсечения совпали побитно; depth/HDR не пустые.
- 1× общий граф: 25 проходов атмосферы/воды/дымки/облаков/небесных тел/поста;
  отказ бюджета атомарен, статика — 0 проходов/загрузок, resize — 0 компиляций.
- 1× модели: восемь видов сущностей и 17 видов блоков; изменения записей и
  отказы бюджета сохраняют прежние публикации. CPU-вершины не создаются.
- 1× height tiles: 9216 пикселей независимого покрытия; защищённый проём и
  Unknown остаются открыты. Точные прокси: 8280 закрытых/936 открытых пикселей,
  совпавших с независимой occupancy-проверкой.
- 53 проверки десяти наборов GPU-регрессий прошли; ещё четыре новые проверки
  моделей/height/прокси проверили 1× отдельно.

Настоящий Dawn проверил водный shader в обоих режимах против f64 закона Снелла:
1× — 532 пикселя пропускания/492 полного внутреннего отражения, максимальная
ошибка HDR 0,000243; 4× — 543/481 и 0,000431. Ошибок shader validation нет;
неверная сторона границы правильно проваливает независимый эталон.

Это проверка вариантов и общей совместимости. Загрузчики, сохранённый выбор
и безопасная переподготовка View при изменении настройки ещё интегрируются;
готовая смена режима из меню пока не заявляется. SMAA этим режимом не реализован.
