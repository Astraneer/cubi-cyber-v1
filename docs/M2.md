# M2: terrain и GPU-оболочка правок

Квад хранится в 16 байтах; GPU декодирует четыре вершины triangle strip без индексного буфера. Арена сохраняет стабильные слоты с поколениями. Матрица, границы и диапазоны занимают 128 байт на объект; движение и скрытие не пересоздают геометрию. Все записи учитываются в бюджете; старые поколения и версии отклоняются.

Compute выполняет frustum → настоящий opaque depth → консервативный Hi-Z → повторную компактацию. Reverse-Z использует очистку 0 и минимум четырёх MSAA-сэмплов; пустая рамка пирамиды остаётся 0. Расширенные границы, near-plane guard и epsilon исключают ложное перекрытие. Шесть indirect-групп разделяют opaque/cutout/water и объекты с маской; bind на страницу отсутствует.

Цвет рисуется в `RGBA16Float`, MSAA 4×. `GreaterEqual` необходим для повторной окраски поверх загруженного opaque prepass. Подготовлены 13 конвейеров при Hi-Z, 8 без него; кадр содержит соответственно 10 и 8 draw-вызовов. Native готовит их в загрузочном потоке. В wgpu 26 отсутствует API асинхронной компиляции браузерных конвейеров: `async`-обёртка этого ограничения не устраняет.

Атлас донора содержит 186 слоёв. Mip-цвет усредняется в линейном свете, дробная alpha используется для A2C; метаданные слоёв 40/41 вынесены из цветовой alpha. Разрешение tint задаётся отдельно для каждой грани. UV привязан к целым координатам страницы, сохраняя фазу повторяемой текстуры при разбиении greedy-квада. Физическая вода относится к M10; текущая водная группа пока рисует обычный материал.

| Проверка на настоящем software Vulkan | Результат |
|---|---|
| Отсечение, изображение 129×97 | 66 → 60 → 54 квада; видимые пиксели побитно совпадают |
| Лес 320×224 | 477 квадов; видимые группы 217/255/5; NVIDIA FLIP = 0, предел 0,01 |
| Декодирование атласа | 8 тестов: CRC, форматы, пределы памяти, mips, alpha, tint, изоляция слоёв |
| Статический план кадра | 10 000 вызовов `needs_redraw` без аллокаций; положительный контроль аллокатора |
| GPU-таймеры | Реальные метки каждого прохода при поддержке `TIMESTAMP_QUERY` |

Тесты не пропускаются при отсутствии GPU. Нулевая аллокация относится к проверке сохранённого плана, а не ко всем активным вызовам wgpu.

## H1: согласованная публикация

Маска содержит 4096 бит, индекс `x + 16*z + 256*y`. CPU-оболочка учитывает всех 27 владельцев в окрестности правки, сохраняя точные грани, материалы, AO и UV. Overlay обходит маску базового меша. `publish_composite` публикует захваченный полный меш вместе с текущей оболочкой; обе аренные аллокации и весь бюджет проверяются до первой GPU-записи. При нехватке второй аллокации изображение и бюджет не меняются. GPU-ревизия публикации монотонна и отличается от версий входов мира.

Centroid-интерполяция и консервативная полупиксельная полоска старой геометрии только возле неизменённого соседа закрывают MSAA-щели между старым greedy и единичными гранями. На дали полоса ограничена одной неизменённой клеткой; уменьшенный предел 0,25 клетки провалил дополнительную проверку и исправлен. У границы страницы предположение о соседе не применяется. Частота fragment shader остаётся пиксельной; обычный terrain не читает маску. Камеры на расстояниях 2×/5×/10× также проходят нулевые дыры и FLIP ≤ 0,001.

| Узкий GPU-тест правки 193×145 | Результат |
|---|---|
| Задержка полного меша | 12 логических кадров 60 Гц = 200 мс; оболочка готова в кадре 1 |
| Простая оболочка | 18 владельцев, 486 чтений, 13 квадов, 1104 байта |
| Отличие временного изображения | 1 пиксель, максимум 2 уровня RGB, FLIP 0,0000047646 |
| Независимая глубина всех MSAA-сэмплов | Неожиданных дыр 0; отключённая оболочка проваливает проверку |
| Отрицательный контроль старого меша | Ошибка 31, выше допустимых 4 для этой сцены |
| Hi-Z против отсутствия отсечения | Побитное совпадение временного изображения |
| Финальный greedy и удаление маски | Побитное совпадение полного независимого эталона |

Временное разбиение допускает FLIP ≤ 0,001 и максимум 4 уровня RGB только в этой узкой синтетической проверке; точные CPU-грани/AO и финальная побитная проверка не ослабляются. Один оставшийся пиксель сохраняет старое затенение неизменённого прямоугольника, который эталон разбивает иначе. Полная нагрузка 64 страницы / 1000 правок/с проверяется отдельно; эти цифры сами по себе не закрывают H1.

## Обновления отдельных владельцев

`publish_owner_patches` и `publish_owner_composite` используют `OwnerPatch` с шестью стабильными гранями. На страницу резервируется 24 576 дескрипторов, но нулевые грани не попадают в indirect-список. Классы шести граней занимают один `u32` на владельца. Первая публикация очищает 16 КиБ состояний; затем меняются только грязные владельцы: 96 байт дескрипторов + 4 байта состояния. Соседние записи объединяются. Маска базы автоматически отключает состояния, покрытые новым полным мешем, без их пересборки и очистки.

Overlay хранит слот и поколение родителя. GPU проверяет оба и включённость базы: после удаления/переиспользования родителя старые грани не рисуются. Отрицательный GPU-тест подтверждает нулевые старые draw-данные и `StaleHandle` без расхода бюджета при попытке привязать прежний overlay к новому поколению.

GPU-тест: первая публикация 18 владельцев — 18 952 байта; один последующий владелец — 868 байт с текущими записями объекта/маски. Из 24 576 зарезервированных слотов рисуются только 13 активных квадов. `Empty` удаляет прежние грани; восстановление возвращает прежнее изображение побитно. После rebase устаревшие состояния не рисуются, финальная замена совпадает побитно. Арена клиента должна явно вмещать резерв всех разрешённых dirty-страниц; небольшая арена M2 этого не гарантирует.

| Полная GPU-нагрузка H1 | Результат |
|---|---|
| 64 страницы, 1000 правок/с, 10 логических секунд | Приняты все 10 000 правок; 600 отправленных и завершённых GPU-кадров |
| Два отложенных полных мешера | 98 rebase, задержка каждого захвата ровно 12 кадров / 200 мс |
| Отклик | В каждом завершённом кадре indirect-счётчик активных граней точно совпал с CPU; публикация в кадре 1 |
| Загрузки | Всего 34 157 008 байт; максимум 333 884 за кадр при лимите 2 097 152 |
| Вместимость | Одновременно 64 overlay, 24 МиБ зарезервированных patch-дескрипторов; отказов вместимости/бюджета 0 |
| Финал | Изображение и минимальная глубина четырёх сэмплов побитно совпали с 64 независимыми полными мешами |

Явная конфигурация нагрузки: 128 слотов, `max_quads=4_194_304`: арена 64 МиБ, visibility 96 МиБ, состояния 2 МиБ. Резерв покрывает 64 худшие базовые страницы и 64 patch-страницы с запасом роста/фрагментации. Правки затрагивают внутренние и видимые клетки; обе группы участвуют в настоящих GPU-списках. Режим нагрузки `CullingMode::None` изолирует стоимость оболочки; побитная проверка Hi-Z выполняется отдельно. Длительность теста на software Vulkan не является заявлением о FPS или бюджете RTX. Обычный CI выполняет 60 кадров / 1000 правок; полная серия включается так:

```sh
H1_GPU_LOAD_FRAMES=600 VK_ICD_FILENAMES="$PWD/.local/mesa/lvp-local.json" cargo test --locked -p render --test terrain_gpu sixty_four -- --nocapture
```

## Подключение M4

`geometry` предоставляет независимым проходам таблицы terrain; тени используют собственную видимость. `attach_lighting` вызывается на загрузке и связывает RGB/skylight и кэш каскадов. После первого кадра возвращается `LatePreparation`. Владелец обновляет тени до terrain, отмечает изменённые границы и вызывает `invalidate` после загрузки света.

Модель: `albedo * ((RGB + 0.15*sky)*AO + 0.85*sky*shadow*NdotL)`. Скалярный игровой свет не прибавляется к RGB. GPU-проверка получила 2379 красных пикселей после 23 328 байт светового тома и нуля байт геометрии. Один scalar block light даёт то же изображение, что тёмный RGB/skylight. Привязка к игровому клиенту и H5 относятся к отдельной приёмке M4.

## Воспроизведение

```sh
source tools/env.sh
VK_ICD_FILENAMES="$PWD/.local/mesa/lvp-local.json" cargo test --locked -p render --test terrain_gpu -- --nocapture
cargo test --locked -p render --lib
cargo clippy --locked -p render --all-targets -- -D warnings
cargo check --locked -p render --target wasm32-unknown-unknown
cargo check --locked -p render --target x86_64-pc-windows-msvc
cargo deny --locked check licenses
cargo run --locked -p render --example compare_frames -- FINAL.png FAST.png OLD.png
```

Последняя команда сравнивает согласованные GPU-fenced PNG: JSON содержит число отличий, максимальную ошибку, настоящий NVIDIA FLIP и положительный чёрный контроль; третий PNG — необязательный отрицательный контроль. Совместимый `compat-nv-flip-sys` сохраняет BSD-уведомления и происхождение; исключённые TinyEXR/miniz не копируются и не компилируются. Лицензионная политика не ослаблялась.
