# Совместимость сохранённых настроек

В CUI1 сохранены32 позиции; старые формы29/30 по-прежнему читаются. Позиция13
`Setting::Taa` выведена из использования, но её допустимые значения0/1
сохраняются при чтении и повторной записи. Значение1 не включает временное
сглаживание и не меняет выбранный пользователем `Setting::Msaa`.

Единственный действующий переключатель сглаживания — `Setting::Msaa`:1 означает
SMAA1x,4 — MSAA4. Устаревшая строка скрыта. Вариант2 не входит в действующий
домен до отдельной проверки настоящего temporal backend и продуктовых оболочек.

У выведенной позиции нет backend receipt: биты `applied` и `reload_required`
для неё не устанавливаются. Общий `pending_graphics_mask` исключает её из
ожидаемой работы. Поэтому сохранённое legacy0/1 не оставляет ложное постоянное
«ожидает применения» и не выдаётся за применённый графический режим.
