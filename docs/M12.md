# M12: звук и локальные ресурсы

## Реализовано и проверено

`audio` содержит общий Rust-микшер с ограниченным пулом до 64 голосов, категориями,
позиционированием, равномощной панорамой, ослаблением по расстоянию, высотой тона,
приоритетами и стабильными петлями машин. Повторное обновление петли не запускает её
сначала. Идентификаторы с поколением защищают от остановки нового голоса старой командой.
Вызов микшера не выделяет и не освобождает память; 64 петли × 10 000 callback проверены
считающим аллокатором и положительным контролем. Разбор Ogg и подготовка ресурсов вынесены
в `Catalog::prepare_all`, то есть в загрузку, а не первый слышимый кадр.

Встроенный каталог: 68 событий / 263 исходных Ogg из белого списка донора. Сохранён
исходный `CREDITS.md`, включая Eelke и Lamoot; `default_sound_credits` доступен браузеру.
Упаковщик должен сохранять также ASSET_CREDITS и исходные уведомления. Нет скачивания
аудио со сторонних серверов. Темп шагов повторяет golden: 2,59/с при ходьбе и 3,37/с при
беге; снег поверх опоры даёт отдельные коэффициенты 0,15 и 0,05.

Native использует cpal (WASAPI в Windows, ALSA при Linux-проверке). Windows MSVC и WASM
компилируются. В облаке физическая звуковая карта отсутствует: реальный запрос вернул
`DeviceUnavailable`, exit 2. Отдельно `tools/native_audio_smoke.sh` проверил настоящий
ALSA null sink и cpal callback (`virtual=true`); это доказательство подключения backend,
а не слышимости, аппаратной задержки или отсутствия пропусков. Банк декодируется до запуска callback.
Последний standalone null-sink smoke приведён ниже вместе с проверкой замены банка.

Браузерный backend использует настоящие AudioBufferSource/Gain/StereoPanner/Convolver,
сохраняет политику autoplay и запускается после действия пользователя. OfflineAudioContext
считает настоящий результат: ошибка панорамы/громкости 1,53e−17, энергия хвоста пещеры
0,010244777, равнины 0, первый отклик на сэмпле 1399. Ogg по умолчанию декодирован в 3648
сэмплов. Это проверка сигнала, отдельно от измерения CPU.

## Приватность импорта

`LocalResources` не зависит от `net`, `server`, телеметрии или HTTP. Импорт zip выполняется
атомарно в локальную память. Ограничены размер архива, число записей, размер записи,
суммарные байты и коэффициент сжатия. Проверены traversal, абсолютные пути, обратные слеши,
symlink, коллизии регистра, усечение и ZIP64; неподдерживаемые варианты явно отклоняются.
Ресурсы не распаковываются по произвольным путям файловой системы. labPBR выдаёт локальные
albedo/normal/specular PNG. Сохраняются CREDITS/LICENSE/NOTICE.

Настоящий file picker загрузил canary zip: 4 записи / 2766 Б; CDP зафиксировал **0 исходящих
запросов** после выбора. Настоящий directory picker `.minecraft` загрузил только индекс
и требуемый звуковой объект: 2 файла / 4312 Б. `launcher_accounts.json`, saves, logs и
остальные файлы отбрасываются до чтения содержимого. Объекты проверяются по локальному
SHA-1 и длине. Исходящих запросов также **0**. Локальные имена и содержимое не входят в
публичную сводку UI, только количества и общий размер. Полные игровые asset-паки не входят
в репозиторий. Звук из локального sounds.json и обычные имена vanilla разрешаются только
через уже имеющиеся локальные файлы; отсутствующий файл не вызывает загрузку по сети.

Windows file/folder dialog подготовлен через rfd без Linux portal/network backend;
MSVC cross-check проходит. Native читает только выбранный индекс и существующие звуковые
объекты, пропускает отсутствующие, отвергает symlink корня/объекта. Отдельный тест проверяет
это настоящими локальными файлами. Необязательные properties/шейдерные метаданные zip
игнорируются без чтения содержимого; их количество входит в сводку, код не исполняется.
Браузерный адаптер повторно использует picker, а поколение выбора не даёт старому
асинхронному чтению заменить более новый импорт. AudioBuffer bank ограничен 512 клипами
и 256 МиБ. Вместе проходят 18 проверок (14 контрактных, 1 native file IO, 2 подготовки банка, 1 замены банка); строгий cargo deny
с новыми зависимостями сохраняет прежний лицензионный список и проходит.

Повтор: `source tools/env.sh`, `cargo test --locked -p audio`,
`bash tools/build_audio_web.sh`, `node crates/audio/tests/browser_smoke.mjs`.
Результат и CPU trace: `.local/artifacts/m12-audio-smoke.json`, `audio-cpu-trace.json`.
Linux-заголовки ALSA установлены только в `.local` через проверенные Debian InRelease →
SHA256 Packages → SHA256 deb; helper `tools/install_audio_deps.py`. Лицензионный whitelist
не расширялся; `cargo deny` проходит.

## H8 и остающаяся интеграция

Chrome 154 дал реальные thread-duration (`tdur`) для единственного
`RealtimeAudioDestinationHandler::Render`, 128 сэмплов, 44 100 Гц, 64 голоса. Среднее CPU:
при последнем повторе равнина 0,3084 мс (345 выборок), пещера 0,3180 мс (344), разность
средних 0,0097 мс. Ранее полученная отрицательная разность −0,0051 мс показывает шум
среды. Это полный аудиограф, а не изолированный таймер convolver. В последнем
повторе p99 равнины/пещеры 0,857/0,624 мс, максимум пещеры 1,275 мс;
**H8 не объявлена принятой**. Эхо по умолчанию выключено.
Нужны повтор на целевом устройстве и отдельный контроль хвостов распределения. Неиспользуемая
свёртка отключается вместе со своими связями/буферами; native имеет эквивалентный ограниченный
18-tap фильтр с проверкой сигнала и отсутствия аллокаций.

Основной браузерный shell подключает общий UI к WebAudio, громкости категорий, жесту
возобновления AudioContext, шагам собственного игрока и hurt/death. Шаги читаются из каждого
реального предсказанного тика (до 64), повторы не проигрываются; неподвижное ожидание не
создаёт фантомных шагов. Узкий `PredictionState::audio_motion` читает движение без
выделения scratch-массивов; 4 catch-up тика проверены с нулём аллокаций/освобождений.
WebAudio считает фактически запущенные/обновлённые/остановленные узлы. Остановленные голоса
имеют ограниченную очередь fade-out и освобождают связи после окончания.

Импорт через общий игровой Rust UI заново подготавливает банк вне draw, порциями с yield;
устаревшее поколение не заменяет новый выбор. Browser smoke проверил приватность при живом
серверном соединении: 422 WebSocket-кадра, 0 утечек canary/аккаунтных байтов и 0 новых HTTP.
F8 download не содержит canary. Подробности: `.local/artifacts/product-ui-smoke.json`.

Native product UI подключает тот же банк, категории громкости, настоящий listener eye,
шаги из фиксированных тиков и hurt/death. X11/XTest сценарий с живым сервером подтвердил
25 938 реально смешанных UI/health voice samples через ALSA null endpoint; аппаратная слышимость
не заявляется. Windows picker/import worker компилируется под MSVC; cloud Linux сообщает,
что этот OS picker доступен в Windows/браузере. `.minecraft` и ZIP читаются только локально.
При смене банка наследуются listener/громкость/echo и счётчик поколений: старый VoiceHandle
не может остановить новый голос. Старые PCM буферы освобождаются вне callback mutex.
Отдельный реальный null endpoint smoke после замены банка: 13 331 430 frames, 3804 voice
samples, 0 missed callbacks, 3535 voice samples из нового банка; callback errors=0.
Это виртуальный endpoint, не измерение аппаратного deadline.

Mine/Place эффекты теперь проходят через ограниченный `ConfirmedBlockSounds`: только
успешный серверный ActionReply создаёт cue; Pending, отказ, повторный ACK и действие
в чужом Space остаются без звука. Два теста проверяют настоящие Connection action/reply,
смену session и 10 000 неизменившихся наблюдений без аллокаций/освобождений. Оба shell
подключают этот маршрут. Шаги отнесены к Players, установка/разрушение — к Blocks;
реальная слышимость всех блоковых действий ещё требует отдельного endpoint-сценария.

Подтверждённые public EntityPose дают отдельный ограниченный маршрут звуков мобов:
переходы hurt/death/sheared и контакты ног из настоящей фазы анимации (включая baby ×3).
Первая картинка, повтор revision, возвращение в радиус, чужой Space и предметы-drop
не воспроизводят старые события. До 16 cue за обновление, 2048 заранее выделенных строк;
четыре теста проводят настоящий строгий codec → Connection, проверяют границу работы и
10 000 неизменившихся наблюдений без аллокаций/освобождений. Оба shell подключены;
отдельный живой сценарий слышимых мобов остаётся до окончательной приёмки.
Окружающие реплики живых мобов планируются локально по подтверждённому public tick
с интервалом 15–25 с, без чтения частного AI/RNG. Пропущенные интервалы не создают очередь
повторов. Звук яйца получает отдельное причинное ACU1-событие после настоящего server WAL;
появление ближайшего egg-drop не используется как доказательство снесённого яйца.
Серверный owner-тест подтверждает reset курицы, egg item и GameplayEvent в одной WAL,
наличие committed egg до публикации cue, тишину для дальней курицы и отсутствие
повторного исторического события после restart/ручного выбрасывания яйца.
Передаются только kind/actor/public tick/Space/позиция; per-peer максимум8 за фазу.
Клиент хранит64 события, подавляет повторы, старые tick и считает transient overflow;
до16 cue обрабатываются за фазу. Проверка strict codec → Connection → CausalSounds →
настоящий PCM исходного Ogg прошла, включая чужой Space, reconnect и10 000 idle
проверок без аллокаций/освобождений. Оба shell подключены. Это не проверка слышимости
пользовательского аппаратного endpoint.

`MachineSounds` читает только public ACTIVE и точную raw cell-view привязку. До 32
постоянных петель, до 2 заголовков/64 hints discovery за фазу; старые binding/revoke/Space
и выход из радиуса немедленно останавливают emitter. Проверяются также raw версии,
меняющиеся без изменения World bytes. Три теста + Clippy проходят, включая активные
cube-машины независимо от владельца их геометрии и отказ ложного Machine hint у сундука. Интегрированный
Vulkan-тест ViewProps провёл настоящий native worker → два near GPU record (halo исключён),
подтверждённый RGB/sky, ACTIVE/ports, фактические indirect draw Chest/Generator → декодированный
PCM машины, затем остановку с хвостом не более 128 frames. 1000 статичных фаз не выделяют
память, не загружают GPU данные, не строят вершины/pipeline. Обновление петли раз в 20 public
тиков сохраняет voice handle и PCM cursor; тест также теряет голос и проверяет его
восстановление следующим обновлением. Смена банка и отключение очищают emitters.
Владельцы подключены к обоим shell; живая продуктовая приёмка продолжается. Этот тест
не доказывает аппаратную слышимость.
Отдельный настоящий Chrome/WebAudio oracle подтвердил сохранение идентичности
AudioBufferSourceNode при refresh, восстановление после stop/вытеснения и сохранение
громкости категории/поколений при замене банка: 5 start, 1 loop update, 3 stop.
Вызов следует за настоящим пользовательским picker-жестом; autoplay policy не отключалась.
Повтор приватности picker: 0 исходящих запросов, учётные файлы не прочитаны.

Второй Vulkan-тест проводит модели через общий View: подтверждённый LIGHT → near Source →
HDR → общий динамический shadow pass сущностей и моделей. Две модели без единого terrain
quad становятся готовы только после настоящего model draw в HDR callback; terrain_frames
остаётся нулём. 1000 неподвижных фаз: 0 аллокаций/освобождений, загрузок GPU и CPU-вершин.
Native готовит каталог в loading worker; браузер имеет отдельный ограниченный worker
CPJ1/CPR1 и новый pool при переподключении. Это не заменяет продуктовую проверку LED
граней машин. Отдельный GPU backend уже проверяет повороты и sRGB-палитру разрешённого
Mek aspect; actual Dawn и игровые снимки нового наложения проверяются отдельно.

блоков/мобов/машин, проверка слышимости на
пользовательском Windows endpoint, H8 на целевом устройстве и удалённый зелёный CI.
Локальные проверки библиотеки не заменяют эти сценарии.
