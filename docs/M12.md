# M12: звук и локальные ресурсы

## Реализовано и проверено

`audio` содержит общий Rust-микшер с ограниченным пулом до 64 голосов, категориями,
позиционированием, равномощной панорамой, ослаблением по расстоянию, высотой тона,
приоритетами и стабильными петлями машин. Повторное обновление петли не запускает её
сначала. Идентификаторы с поколением защищают от остановки нового голоса старой командой.
Вызов микшера не выделяет и не освобождает память; 64 петли × 10 000 callback проверены
считающим аллокатором и положительным контролем. Разбор Ogg и подготовка ресурсов вынесены
в `Catalog::prepare_all`, то есть в загрузку, а не первый слышимый кадр.

Встроенный каталог: 68 событий / 263 исходных Ogg из белого списка донора. Сохранён
исходный `CREDITS.md`, включая Eelke и Lamoot; `default_sound_credits` доступен браузеру.
Упаковщик должен сохранять также ASSET_CREDITS и исходные уведомления. Нет скачивания
аудио со сторонних серверов. Темп шагов повторяет golden: 2,59/с при ходьбе и 3,37/с при
беге; снег поверх опоры даёт отдельные коэффициенты 0,15 и 0,05.

Native использует cpal (WASAPI в Windows, ALSA при Linux-проверке). Windows MSVC и WASM
компилируются. В облаке физическая звуковая карта отсутствует: реальный запрос вернул
`DeviceUnavailable`, exit 2. Отдельно `tools/native_audio_smoke.sh` проверил настоящий
ALSA null sink и cpal callback (`virtual=true`); это доказательство подключения backend,
а не слышимости, аппаратной задержки или отсутствия пропусков. Декодирование при загрузке
может временно занимать управляющий mutex; callback не блокируется и считает пропуски.

Браузерный backend использует настоящие AudioBufferSource/Gain/StereoPanner/Convolver,
сохраняет политику autoplay и запускается после действия пользователя. OfflineAudioContext
считает настоящий результат: ошибка панорамы/громкости 1,53e−17, энергия хвоста пещеры
0,010244777, равнины 0, первый отклик на сэмпле 1399. Ogg по умолчанию декодирован в 3648
сэмплов. Это проверка сигнала, отдельно от измерения CPU.

## Приватность импорта

`LocalResources` не зависит от `net`, `server`, телеметрии или HTTP. Импорт zip выполняется
атомарно в локальную память. Ограничены размер архива, число записей, размер записи,
суммарные байты и коэффициент сжатия. Проверены traversal, абсолютные пути, обратные слеши,
symlink, коллизии регистра, усечение и ZIP64; неподдерживаемые варианты явно отклоняются.
Ресурсы не распаковываются по произвольным путям файловой системы. labPBR выдаёт локальные
albedo/normal/specular PNG. Сохраняются CREDITS/LICENSE/NOTICE.

Настоящий file picker загрузил canary zip: 4 записи / 2766 Б; CDP зафиксировал **0 исходящих
запросов** после выбора. Настоящий directory picker `.minecraft` загрузил только индекс
и требуемый звуковой объект: 2 файла / 4312 Б. `launcher_accounts.json`, saves, logs и
остальные файлы отбрасываются до чтения содержимого. Объекты проверяются по локальному
SHA-1 и длине. Исходящих запросов также **0**. Локальные имена и содержимое не входят в
публичную сводку UI, только количества и общий размер. Полные игровые asset-паки не входят
в репозиторий. Звук из локального sounds.json и обычные имена vanilla разрешаются только
через уже имеющиеся локальные файлы; отсутствующий файл не вызывает загрузку по сети.

Windows file/folder dialog подготовлен через rfd без Linux portal/network backend;
MSVC cross-check проходит. Native читает только выбранный индекс и существующие звуковые
объекты, пропускает отсутствующие, отвергает symlink корня/объекта. Отдельный тест проверяет
это настоящими локальными файлами. Необязательные properties/шейдерные метаданные zip
игнорируются без чтения содержимого; их количество входит в сводку, код не исполняется.
Браузерный адаптер повторно использует picker, а поколение выбора не даёт старому
асинхронному чтению заменить более новый импорт. AudioBuffer bank ограничен 512 клипами
и 256 МиБ. Вместе проходят 14 контрактных и 1 native file IO тест; строгий cargo deny
с новыми зависимостями сохраняет прежний лицензионный список и проходит.

Повтор: `source tools/env.sh`, `cargo test --locked -p audio`,
`bash tools/build_audio_web.sh`, `node crates/audio/tests/browser_smoke.mjs`.
Результат и CPU trace: `.local/artifacts/m12-audio-smoke.json`, `audio-cpu-trace.json`.
Linux-заголовки ALSA установлены только в `.local` через проверенные Debian InRelease →
SHA256 Packages → SHA256 deb; helper `tools/install_audio_deps.py`. Лицензионный whitelist
не расширялся; `cargo deny` проходит.

## H8 и остающаяся интеграция

Chrome 154 дал реальные thread-duration (`tdur`) для единственного
`RealtimeAudioDestinationHandler::Render`, 128 сэмплов, 44 100 Гц, 64 голоса. Среднее CPU:
при последнем повторе равнина 0,3457 мс (345 выборок), пещера 0,3406 мс (348); разность
средних −0,0051 мс показывает шум среды, а не отрицательную цену свёртки. Ранее получены
0,2865/0,3093 мс. Это полный аудиограф, а не изолированный таймер convolver. В последнем
повторе p99 равнины/пещеры 1,285/1,036 мс, максимум пещеры 1,884 мс;
**H8 не объявлена принятой**. Эхо по умолчанию выключено.
Нужны повтор на целевом устройстве и отдельный контроль хвостов распределения. Неиспользуемая
свёртка отключается вместе со своими связями/буферами; native имеет эквивалентный ограниченный
18-tap фильтр с проверкой сигнала и отсутствия аллокаций.

До приёмки M12 ещё нужны: подключение реальных игровых событий и настроек к обоим shell,
вызов file/directory picker из общего Rust UI, применение локальных labPBR изображений
рендерером, проверка слышимости на пользовательском Windows endpoint, удалённый зелёный CI.
Локальные проверки библиотеки и отдельного браузерного сценария не заменяют эту интеграцию.
