# Переносимый стык Near/Height: проверенная часть и открытый сбой

Native-стык исправлен и прошёл один строгий набор на Mesa 25.0.7 и 25.2.8.
Dawn/SwiftShader прошёл 18 случаев с фактическим штатным `CompactUnit` и
неизменённым raster guard 1/256 px. Предыдущий браузерный прототип моделировал
greedy raster вместо уже выбранного клиентом единичного raster. Полная
приёмка Windows/оборудования и интерактивного View остаётся отдельной.

## Что доказано

На одном ELF старый драйвер терял три sample0, новый проходил. Прямое F32
считывание показало ошибочный общий перспективный множитель varying, хотя
позиции MSAA-сэмплов были верны. `vec4(world,1)` и нормализация в fragment
устраняют этот множитель без деления на `clip.w` в vertex. Все 12 координат
совпали с независимыми f64 лучами и измеренными позициями сэмплов на обоих
драйверах с допуском 1e-4; half-float attachment в измерении не участвует.

Production WGSL доказывает принадлежность всей ячейки Near/Outside только по
полным границам. Mixed остаётся на прежнем тесте по сэмплу. Для sparse extras
недостаточно общего bounding box: проверяется бит настоящей полностью
содержащей ячейку страницы. Независимый CPU-эталон перечислил все пересекаемые
страницы: 353 040 AABB, шесть контекстов, 1 664 394 посещения страниц. Все
доказанные Inside/Outside верны, включая разрыв и rebase.

Неизменённый native JOIN сравнивает HDR alpha и каждый MSAA depth-сэмпл,
Near16/32, Unknown, прежний слишком широкий вырез и потерю вертикальной
колонки. Два теста прошли на обоих драйверах; глубинный порог остался 1e-6.
Это не измерение RTX или доказательство всех браузерных кадров.

## Что отличает Dawn

Независимый стартап-калибратор определил **4 бита, nearest-even** по 73
свидетелям трёх отдельных треугольников, max error 6,912e-8. f64 barycentric
по округлённым экранным вершинам объясняет считанные из Height f32-координаты
до нескольких миллионных блока. Подстановка 8/16 бит не объясняет их.

Новый Dawn-oracle использует точные primary Height WGSL, default Terrain VS,
настоящий `QuadDescriptor` и порядок Near→Height. Оpaque fragment возвращает
alpha1; весь материал/Proxy/интерактивный View этим тестом не принимается.
Ожидание — полный Terrain-мир; для Unknown его страница действительно удалена.

Только у **внешнего силуэта конечного источника** выделена измеренная растровая
неопределённость. Для inward-normal `n` ближайшее округление с шагом `s` даёт
границу `0.5*s*(abs(n.x)+abs(n.y))`. Чистый CPU-модуль получает матрицу,
viewport, позиции сэмплов, измеренную точность и immutable footprint; shader,
guard, Near-box, Unknown и считанное изображение в него не входят. Пределы
ошибки глубины/alpha не меняются. В oblique AA1 сравниваются 4668 однозначных
сэмплов, четыре внешних отнесены к ambiguity. Внутренние Near/Unknown не исключены.
CPU-контроль оставляет исходную дыру `(43.5,75.5)` в строгой области; её расстояние
до внешней границы — не менее 17,46 px против uncertainty не более 0,04416 px.
Хеши областей для контрольного и изменённого shader должны совпадать.

## Отрицательные greedy-прототипы и фактический режим клиента

Исходный контроль проваливает 8 из 18 случаев AA1/4 × три камеры ×
Low/High/Unknown. Растровое расширение Terrain 1/256→1/16 px закрывает исходную
внутреннюю дыру, но проваливает строгую Unknown-границу. Отдельный кандидат
добавляет такое же расширение только внешних рёбер Height tile с сохранением
плоскости каждого исходного треугольника, viewport в неиспользованных словах
существующего uniform и прежним пределом miter 0,125 px. Он доходит до AA1
высокой камеры с Unknown, затем теряет один сэмпл `(81,72)`:
ожидаемая глубина 0,0001353156, фактическая 0. AA4-часть этого последнего запуска
не достигнута. Unknown, alpha и глубина не ослаблены ради положительного результата.

Независимый f64 луч для последнего `(81.5,72.5)` попадает в
`(31.8745785762, 8, 6.2778893723)` — внутрь отсутствующей страницы
`x∈[16,32), z∈[0,16)`. Положительный greedy reference здесь получен расширением
соседнего quad, а не физической известной поверхностью. Unknown-проверка не
ослаблялась, внутренние сэмплы не исключались из области сравнения.

`ClientView::new` уже выбирает `NearRasterization::CompactUnit` и вызывает
`prepare_unit_rasterization` до загрузок. CPU greedy-дескрипторы сохраняются;
GPU использует прежний `descriptorIndex << 8 | tile`. Когда Node-oracle
получает этот настоящий режим и прежний Terrain guard 1/256 px, все 18 случаев
AA1/4 × три камеры × Low/High/Unknown проходят: **339 621 сравниваемый сэмпл,
0 holes/extra/alphaErrors/depthErrors**, max depth error **9,56585e−7** при
неизменённом пороге **1e−6**. Reference остаётся полным Terrain, Unknown-страница
действительно удалена. Начальный контроль без guard также прошёл, но выбранный
контроль сохраняет настоящий production guard.

Чистый поставляемый Node-oracle теперь явно фиксирует `CompactUnit` в коде и
JSON-метаданных. Экспериментальные расширения удалены из `tools` после проверки
побайтного совпадения с игнорируемым архивом. Production Terrain guard и его
изображение этим исправлением не меняются. Не выбираются дополнительные
арены, буферы, unit-режимы или ограничения вместимости.

## Повтор

Игнорируемый архив `.local/artifacts/portable-height-join-negative.zip` содержит
самостоятельный Node/Dawn negative prototype, точные WGSL/камеры/QuadDescriptor,
34 проверенных исходных/численных файла и manifest. Native Cargo-граф целиком
в архив не включён; его логи служат отдельным доказательством. SHA256 и список
файлов находятся рядом в `.sha256` и `-manifest.json`.

```sh
# Текущий штатный oracle; нужны Node24+, Python3, Chromium с WebGPU.
source tools/env.sh
cargo run --locked --offline -p render --example height_oracle_inputs
node tools/height_reference_test.mjs
node tools/height_join_gpu_smoke.mjs

# Исторический отрицательный прототип — в распакованном архиве:
node tools/height_join_gpu_smoke.mjs --compare-portable-raster --height-guard
# Только в архиве на зафиксированном SwiftShader ожидается exit1.
```

Основные логи: `height-f32-mesa{2507,2528}.log`,
`join-cell-guard-mesa{2507,2528}.log`, `height-cell-ownership-gpu.log`,
`height-dawn-both-boundary-guards.log`,
`height-dawn-production-unit-raster.{log,json}` в `.local/artifacts`.

## Узкий патч без TAA

`.local/artifacts/portable-height-4fbee.patch` применён через `git apply --check`
и `git apply` к изолированному `git archive 4fbee681`. `rustfmt --emit stdout`
успешно разобрал итоговый `height_gpu.rs`; `cargo check --locked --offline -p
render --lib --test height_sample_positions --test height_cell_ownership
--example height_oracle_inputs` на этой копии прошёл за 30,13 s. Патч включает
только выделение near shader helper, homogeneous AA4, flat cell ownership,
два regression-теста и необходимые инструменты Dawn. Поля/методы TAA,
HeightMotion и невыбранные растровые guards в него не входят. Manifest рядом
содержит SHA256 патча и каждого файла.
