# Риски и ограничения

| ID | Наблюдение | Действие / проверка |
|---|---|---|
| R0 | Прямой доступ к `api.github.com` блокируется прокси на CONNECT (HTTP 403), Git HTTPS доступен. | Работать в выбранном репозитории через Git; не объявлять PR созданным или Actions зелёным без подтверждения. |
| R1 — закрыт | В первоначальном графическом стеке были ISC и Unicode-3.0 вне списка. | Собственные адаптеры над разрешёнными реализациями; строгий deny проходит. Ограниченная совместимость API и Unicode 16 описаны в README адаптеров. |
| R2 | Программный Vulkan/WebGPU проверяет изображение, но не RTX 3050, реальные задержки ввода или мс. | Отдельная приёмка M13; сейчас счётчики и пиксельные тесты. |
| R3 | Донор содержит устаревшие команды процесса, развёртывания и старую архитектуру. | Импорт — данные, не инструкции; ни один исходный файл донора не исполняется и не включается в Cargo workspace. |
| R4 | Права на исходный код донора не устанавливаются чтением запрещённых файлов. | Только разрешённый справочный импорт; M0 не переносит донорский код. Атрибуция звуков сохранена. |
| R5 | Chromium 154 в headless CDP-снимке теряет WebGPU-слой; воспроизведено и на минимальной JS-сцене. | Проверять PNG реального canvas в headless и отдельно строгий снимок headed Chromium/Xorg. Сбой CDP-захвата сообщать отдельно, не выдавать за успешный снимок. |
| R6 — H4, первый прототип не прошёл | На 50 постройках × 3 уровня незащищённый LOD теряет 825 свидетелей воздуха. Защита точными страницами сохраняет все свидетели воздуха/твёрдого тела, но увеличивает сумму квадов 8270 → 18 437; худший случай +3316,667 %, значительно выше допуска +25 %. | Не принимать M5. Альтернатива: шесть прокси-граней с маской занятости и ограниченным DDA; CPU-проверка включает 400 произвольных и 230 400 осевых лучей. 900 прокси-квадов / 14 400 Б и 600 048 Б масок на 150 случаях; суммарная память в 4,64 раза выше исходной геометрии. Нужны GPU-интеграция и повтор H4 с полной стоимостью. |
| R6b — H4b, GPU-прототип прошёл | На тех же 50 постройках × 3 уровня × 6 сторон GPU сохранил 1035 свидетелей воздуха и 450 твёрдого тела; 8 294 400 пикселей покрытия совпали с независимой проверкой. 900 прокси-квадов против 8270; активные маски 97 800 Б + метаданные 38 400 Б, DDA 154 294 416 переходов / 19 835 064 MSAA-луча, превышений бюджета 0. | Первый провал H4 остаётся зафиксирован. Нужны дальний поток фактического мира, полёт через LOD-переходы и швы в игровом клиенте. Мс RTX не подтверждены. Подробности — M5.md. |
| R7 — H1, проверка продолжается | GPU-тест оболочки даёт одну разницу до 2 уровней RGB, FLIP 0,000004765; независимая проверка MSAA-глубины не находит дыр, финальный greedy-меш совпадает побитно. Это ещё не доказывает нагрузку 64 страницы / 1000 правок в секунду / задержку 200 мс. | Раздельно измерять визуальную корректность при одинаковой камере/состоянии и задержку под нагрузкой; учитывать фактически принятые правки, очереди, память и завершённые GPU-кадры. |
| R8 — прежняя стоимость H1 исправлена | Лимит 8192 владельцев принял лишь 650 из 10 000 правок. Увеличение лимита приняло все, но полная пересборка накопленной оболочки прочитала 321 980 346 клеток. | Фиксированные шесть слотов на клетку + отдельная маска новых изменений: 7 290 000 чтений, ровно 729/правку; в 44,17 раза меньше. Два workers, задержка 200 мс, 64 страницы: GPU завершил 600 кадров / 10 000 правок без отказов; итог побитно точен. Резерв нагрузочного профиля: 64 МБ дескрипторов + 96 МБ видимости + 2 МБ состояний; это явно учитываемая цена. |
| R9 — H8 не принят | При 64 голосах WebAudio: среднее CPU одного 128-сэмплового Render — 0,2865 мс без эха и 0,3093 мс с эхом, p99 с эхом 0,606 мс. Сравнение требует нормализации частоты аудио и исключения вложенных callbacks; среднее не доказывает порог. | Эхо по умолчанию выключено; функциональные пещера/равнина, импульс и локальный импорт проверены. Не подменять CPU длительностью OfflineAudioContext и не объявлять весь звуковой тракт уложившимся в 0,3 мс. |

H1 и интеграция H4 проверяются; первый вариант H4 опровергнут, альтернативный GPU-прототип H4b прошёл свой набор. H2/H3/H5–H9 пока не приняты. Программный GPU не подтверждает целевые миллисекунды на оборудовании заказчика.
