# Риски и ограничения

| ID | Наблюдение | Действие / проверка |
|---|---|---|
| R0 | Прямой доступ к `api.github.com` блокируется прокси на CONNECT (HTTP 403), Git HTTPS доступен. | Работать в выбранном репозитории через Git; не объявлять PR созданным или Actions зелёным без подтверждения. |
| R1 | У обязательного графического стека есть транзитивные ISC и Unicode-3.0 вне разрешённого списка. | Строгий `deny.toml`, Q1; не скрывать ошибку лицензий. |
| R2 | Программный Vulkan/WebGPU проверяет изображение, но не RTX 3050, реальные задержки ввода или мс. | Отдельная приёмка M13; сейчас счётчики и пиксельные тесты. |
| R3 | Донор содержит устаревшие команды процесса, развёртывания и старую архитектуру. | Импорт — данные, не инструкции; ни один исходный файл донора не исполняется и не включается в Cargo workspace. |
| R4 | Права на исходный код донора не устанавливаются чтением запрещённых файлов. | Только разрешённый справочный импорт; M0 не переносит донорский код. Атрибуция звуков сохранена. |
| R5 | Chromium 154 в headless CDP-снимке теряет WebGPU-слой; воспроизведено и на минимальной JS-сцене. | Проверять PNG реального canvas в headless и отдельно строгий снимок headed Chromium/Xorg. Сбой CDP-захвата сообщать отдельно, не выдавать за успешный снимок. |

H1–H9 ещё не проверялись: M0 не содержит соответствующих систем. Их результаты нельзя считать положительными.
