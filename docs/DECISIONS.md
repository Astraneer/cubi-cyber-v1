# Решения

| Дата | Вопрос | Выбор и причина | Как изменить |
|---|---|---|---|
| 2026-10-25 | Исходное ТЗ | Приложенный заказчиком текст сохранён без изменений как `SPEC.md`; репозиторий был пустым. | Только явным изменением ТЗ. |
| 2026-10-25 | Границы | Работа только в `Astraneer/cubi-cyber-v1`. Донор — справочные данные только из §2, закреплённый коммит. Команды, VPS и процессные указания из донора не выполняются. | Изменить §0/§2 до расширения импорта. |
| 2026-10-25 | Первый срез | M0: 15 крейтов, небо, измерительная инфраструктура и проверки. Пустые крейты обозначены как каркас; механики M1–M13 не имитируются. | Следующий этап после приёмки M0. |
| 2026-10-25 | Инструменты | Rust 1.90.0, wgpu 26.0.1, winit 0.30.12; точные зависимости и Cargo.lock. Кэши и инструменты локальны репозиторию. | Отдельное обновление lockfile с теми же проверками. |
| 2026-10-25 | Изображение M0 | Один процедурный WGSL-градиент для native/WebGPU, MSAA 4×, до 2 кадров в работе. Никаких внешних ассетов. Полная атмосфера и HDR — дальнейшие этапы. | Заменить проход с сохранением smoke-тестов. |
| 2026-10-25 | Интерфейс | В M0 браузерный HTML — только запуск и ошибка отсутствия WebGPU; общие игровые экраны Rust будут выбраны к M11. | Записать выбор egui/своего UI перед реализацией экранов. |
| 2026-10-25 | Лицензии | Строго сохраняется список §0.2: ISC и Unicode-3.0 автоматически не разрешаются, даже если эти зависимости нужны wgpu/winit. Вопрос прав вынесен в QUESTIONS. | Только решение заказчика о допустимых лицензиях либо проверенная замена зависимостей. |
| 2026-10-25 | Доказательство производительности | В облаке проверяются корректность и количество работы. Нулевые аллокации телеметрии не выдаются за нулевые аллокации драйвера или полный бюджет кадра. | Добавлять измеряемые пути по мере реализации. |
| 2026-10-25 | Программный native | Встроенный SwiftShader поддерживает offscreen Vulkan, но не X11 surface. Для настоящего окна используется lavapipe из подписанного пакета Debian, локально в `.local/mesa`. | Удалить локальный пакет и использовать проверенный системный ICD. |
| 2026-10-25 | Запуск pipeline | В M0 единственный pipeline создаётся синхронно до цикла кадров; web-диагностика отдельно создаёт ещё один. Компиляций в кадре нет. Асинхронная подготовка таблицы вариантов §6.1 ещё не реализована. | Перед добавлением вариантов M2 вынести подготовку с экрана загрузки в поддержанный асинхронный путь. |
| 2026-10-25 | Цвет native/Web | Общая функция неба выдаёт линейный свет. Native sRGB attachment кодирует аппаратно; браузерный unorm canvas получает стандартное кодирование из варианта того же WGSL. Выбор один раз при запуске; линейный и sRGB offscreen-эталоны проверяются отдельно. | При HDR M2/M10 явно изменить договор тонмаппинга и эталоны обеих платформ. |
