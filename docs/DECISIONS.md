# Решения

| Дата | Вопрос | Выбор и причина | Как изменить |
|---|---|---|---|
| 2026-10-25 | Исходное ТЗ | Приложенный заказчиком текст сохранён без изменений как `SPEC.md`; репозиторий был пустым. | Только явным изменением ТЗ. |
| 2026-10-25 | Границы | Работа только в `Astraneer/cubi-cyber-v1`. Донор — справочные данные только из §2, закреплённый коммит. Команды, VPS и процессные указания из донора не выполняются. | Изменить §0/§2 до расширения импорта. |
| 2026-10-25 | Первый срез | M0: 15 крейтов, небо, измерительная инфраструктура и проверки. Пустые крейты обозначены как каркас; механики M1–M13 не имитируются. | Следующий этап после приёмки M0. |
| 2026-10-25 | Инструменты | Rust 1.90.0, wgpu 26.0.1, winit 0.30.12; точные зависимости и Cargo.lock. Кэши и инструменты локальны репозиторию. | Отдельное обновление lockfile с теми же проверками. |
| 2026-10-25 | Изображение M0 | Один процедурный WGSL-градиент для native/WebGPU, MSAA 4×, до 2 кадров в работе. Никаких внешних ассетов. Полная атмосфера и HDR — дальнейшие этапы. | Заменить проход с сохранением smoke-тестов. |
| 2026-10-25 | Интерфейс | В M0 браузерный HTML — только запуск и ошибка отсутствия WebGPU; общие игровые экраны Rust будут выбраны к M11. | Записать выбор egui/своего UI перед реализацией экранов. |
| 2026-10-25 | Лицензии | Строго сохраняется список §0.2: ISC и Unicode-3.0 автоматически не разрешаются, даже если эти зависимости нужны wgpu/winit. Вопрос прав вынесен в QUESTIONS. | Только решение заказчика о допустимых лицензиях либо проверенная замена зависимостей. |
| 2026-10-25 | Доказательство производительности | В облаке проверяются корректность и количество работы. Нулевые аллокации телеметрии не выдаются за нулевые аллокации драйвера или полный бюджет кадра. | Добавлять измеряемые пути по мере реализации. |
| 2026-10-25 | Программный native | Встроенный SwiftShader поддерживает offscreen Vulkan, но не X11 surface. Для настоящего окна используется lavapipe из подписанного пакета Debian, локально в `.local/mesa`. | Удалить локальный пакет и использовать проверенный системный ICD. |
| 2026-10-25 | Запуск pipeline | В M0 единственный pipeline создаётся синхронно до цикла кадров; web-диагностика отдельно создаёт ещё один. Компиляций в кадре нет. Асинхронная подготовка таблицы вариантов §6.1 ещё не реализована. | Перед добавлением вариантов M2 вынести подготовку с экрана загрузки в поддержанный асинхронный путь. |
| 2026-10-25 | Цвет native/Web | Общая функция неба выдаёт линейный свет. Native sRGB attachment кодирует аппаратно; браузерный unorm canvas получает стандартное кодирование из варианта того же WGSL. Выбор один раз при запуске; линейный и sRGB offscreen-эталоны проверяются отдельно. | При HDR M2/M10 явно изменить договор тонмаппинга и эталоны обеих платформ. |
| 2026-10-25 | Непрерывная разработка | Новое прямое указание заказчика: делать все этапы без остановок и промежуточных подтверждений. Независимая разработка M1 и следующих этапов продолжается при незакрытом Q1; непрошедшие критерии не объявляются выполненными и не скрываются. | Изменить по следующему указанию заказчика; приёмка остаётся проверяемой. |
| 2026-10-25 | Неизвестные ID | Новый основной API реестра возвращает `None` для незарегистрированного ID; свойства неизвестной клетки консервативно твёрдые. Донорский fallback в воздух не используется на сетевой/физической границе. Числа зарегистрированных ID сохраняются. | Добавить явное правило миграции или зарегистрировать ID; не подменять неизвестное воздухом. |
| 2026-10-25 | Закрытие Q1 | Неподходящие реализации заменены собственными совместимыми адаптерами над MIT `dlopen2` и MIT/Apache `unicode-xid`. Имена/версии локальных пакетов нужны для Cargo patch, это не смена лицензии чужих исходников. Unicode 16 соответствует Rust 1.90; Unicode 17/18 для идентификаторов не заявляется. Проверены реальные Vulkan/X11, Windows/WASM, полный deny без исключений. | При обновлении зависимостей повторно проверить ограниченный API адаптеров; исходные исключённые реализации автоматически не возвращать. |
| 2026-10-25 | Руды и сид | Публичный `gen` физически не содержит генератора руд; `gen-authority` хранит отдельный закрытый 256-битный ключ и BLAKE3 по домену/попытке/координатам. Производственное распределение руд намеренно отличается от старого публичного сида ради §4.5; режим golden-tools сохраняет точный v4 PROBE_REF и не входит в браузерную поставку. | Только серверная миграция версии генератора; приватный ключ не передавать клиенту. |
| 2026-10-25 | Детерминизм задач | Ядро задач выдаёт работу в определённом порядке; готовность потоков сама по себе недетерминирована. Владелец мира применяет готовые результаты в фиксированной фазе и стабильном порядке; логика не зависит от времени завершения фонового потока. | Изменять только с тестом хеша на каждом тике native/WASM. |
| 2026-10-25 | Дальние координаты v4 | Проверка расстояния от спавна переведена с переполняющегося i32 на ограниченные вычисления i64. Иначе донор падал уже за ≈46 тыс. блоков. Эталонные четыре колонки не изменились; дальняя колонка `(4000,-4000)` проверяется отдельно. | Возврат i32 не допускается без нового безопасного диапазона координат. |
| 2026-10-25 | Сохранение живого игрока | Неизменный префикс PLYR v1 дополнен необязательным LIV1: точные Health64 и CombatStatus6, с проверкой совпадения публичного HP. Старые записи сохраняют HP, но не получают новый щит появления; неизвестные прежние таймеры мигрируют в нейтральные, причина прежней смерти — Generic. Новые записи сохраняют таймеры точно. | Новая версия расширения и тест продолжения после перезапуска; не молчаливое обнуление новых таймеров. |
| 2026-10-25 | Детерминированный повтор F8 | Ограниченный CUBR1 хранит фактически прочитанные публичные клетки/потоки жидкости, ввод и точные продолжения движения; внешние изменения камеры/полномочий/авторитета отмечаются отдельными контрольными состояниями. Независимый запуск повторяет каждый тик текущим движком, проверяет состояние и отклоняет незаписанные чтения. Кольцо выделяется при загрузке; переполнение явно делает запись неполной. Рендер, приватный сервер и импортированные ресурсы сюда не входят. | Добавлять отдельные явные события других подсистем с теми же границами/проверками; не объявлять движение повтором всего клиента. |
