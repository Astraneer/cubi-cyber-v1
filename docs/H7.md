# H7 — стриминг по времени до последствия

Проверенный кандидат общего кэша страниц отклонён: предел 48 не даёт требуемых 2× памяти, а предел 27 даёт 2,842× в измеренном тракте, но нарушает готовность настоящей сцены. Выбран прежний кэш. Это результат данного кандидата и сценария, не опровержение отдельного будущего кэша для физики.

В игнорируемом прототипе используются настоящие `ClientScene`, `Replica`, публичный PageSnapshot codec, аутентифицированные фрагментируемые UDP-каналы и `SimulatedLink`75±20 мс/2% потерь. На стороне источника — реальные `Player`, `SurvivalRuntime`, `ItemRuntime`, `MobRuntime`. Движущийся игрок приближается к удалённой плотине; плотина снимается на tick10, вода распространяется настоящим ограниченным планировщиком. В маршруте есть подбор предмета, ИИ/физика зомби и планы ударов. Всего 1176 известных страниц,360ticks, две смены направления. Три запуска дают 1080 исходных тиков и 3240 повторов плана игрока. Каждый источник имеет 40 записей жидкости, один подбор, два контакта ближнего боя и 43 тика в воде. Хеш состояния источника во всех запусках: `ddc6f8b4cc886df1ff5b4d8bd51ef486a24d03b2812367d6d657b55abbd522ce`.

TTC ранжирует те же 125 желаемых страниц по текущим позиции/скорости на горизонте 20 тиков и текущим публичным координатам акторов. Он не читает будущий маршрут или будущие клетки. Существующие транспортные лимиты сохранены:16 надёжных посылок в полёте,512 пакетов/524288 Б на имитационный канал. Очередь коалесцируется по странице; получение старого снимка после смены интереса не возвращает страницу в кэш. Никакой подстановки Air вместо Unknown нет. Выполняются до четырёх настоящих задач мешинга в тик.

Все три политики в каждом запуске сохраняют полное публичное состояние плана игрока, контакты с водой, доступность подбора и два плана ударов без пропусков. Есть отдельные фоновые Unknown предметов; они не скрыты за нулём критических контактов. Повторы планов начинаются с одинакового канонического состояния каждого тика, поэтому это локальная проверка зависимости от доступных клеток, а не доказательство интегрированного rollback. Для детерминированности настоящие native path jobs завершаются между логическими тиками без продвижения акторов.

Во втором запуске порядок политик обращён; все счётчики seed1, включая аллокации, совпали точно. Другой seed сети даёт пик 19698179–19745259 Б /12355844–12388644 Б /6930627–6932467 Б,166–161 готовый тик у 125 и ноль у обоих TTC. Проверка трёх логов проходит. Независимая сборка замороженного снимка воспроизвела хеш и все строки seed1 точно.

Память измеряет живые принадлежащие тракту heap-выделения: транспорт и очереди, Replica, настоящий Scene/World с журналом, снимки для мешинга. Учитываются конструкторы и потоковые фазы; временные объекты удаляются до окончания интервала. Общий холодный источник, прогретый TLS, диагностические owner-пробы, стек, GPU/драйвер, полный View и освещение сюда не входят. Это не RSS и не оценка памяти всего продукта. Уменьшение только числа страниц завышало бы выигрыш: у настоящего тракта остаются журнал, очереди и версии.

Кандидат 27 проходит узкую проверку памяти/контактов, но не готовность существующего Scene: для 27 видимых страниц нужны 125 страниц halo. Прототип оптимистично начинает движение после загрузки разрешённого числа страниц; настоящий ready-gate не дал бы начать этот маршрут. Поэтому результат не принимается в общий кэш клиента. Нет утверждений о полном GPU-изображении, свете, actor-DTO потоке, уроне/здоровье/respawn или Server/WAL: здесь исполняются настоящие планы владельцев, но не полный серверный бой. Целевые миллисекунды оборудования не измерены.

По §11 альтернативная политика осталась только в игнорируемом воспроизводимом архиве. Production-реализации, экспорта и CI-теста для неё нет. Архив: `.local/artifacts/h7-consequence-prototype.zip`; содержит снимок 18 библиотек, необходимые разрешённые ассеты, три лога, скрипты анализа и отдельный frozen-verification. Зависимости реестра берутся из lockfile. Команды — `README-H7.md` внутри архива: после настройки Rust1.90/ALSA выполнить `cargo run --locked --offline --manifest-path .local/experiments/h7-consequence/Cargo.toml -- 1`, затем `verify.py` и `analyze.py`. Собственный standalone-target обязателен, чтобы не смешивать метаданные зависимостей с основным workspace. Clippy прототипа проходит с `-D warnings`.
