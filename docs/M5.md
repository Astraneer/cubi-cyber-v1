# M5: сводки мира и маскированные прокси

Первый H4 с сохранением точных мешей провалил бюджет. Непрозрачный backend H4b использует шесть неявных квадов коробки, маску занятости и глубину фактической поверхности. Текущий PXP2 добавляет обычные 16-Б квады Cutout для правильных A2C и фона за листвой. Результаты ниже подтверждают отдельные контракты рендера и потока; общий статус этапа ведётся в `docs/STATUS.md`.

`render::lod_gpu::LodProxyGpu` использует стабильные слоты с поколениями, арены данных, собственную compute-компактацию видимых объектов и два групповых indirect draw в общем HDR/MSAA 1×/4× проходе terrain: непрозрачные коробки и Cutout-квады. Данные приходят только из `PublicPage`, очищенного от закрытых сведений. Unknown не превращается в воздух: неполные данные отклоняются до замены предыдущего покрытия. Вода сохраняет отдельный тип, но этот непрозрачный backend её отклоняет для отдельного водного прохода.

На GPU хранятся маска занятости, префиксы popcount, битовые индексы палитры и пары atlas-layer/tint. Лишняя маска Known не передаётся: все 4096 входов проверяются до упаковки. Служебная таблица объекта занимает 256 байт, включает прямую/обратную матрицу и границы. Ray traversal ограничен 46 переходами на сэмпл. Мип выбирается по проекции размера клетки. По желанию загрузки подключаются стабильные тени M4 и публичный RGB/skylight объекта; режим инструментирования явно добавляет счётчики fragment shader.

## Дальний поток и границы

Обычный горизонт использует сводки 4³ фактического мира. Только выбранные защищённые листья получают сжатые публичные геометрические маски и atlas-палитры. `server::lod::geometry_from_page` работает в задаче по неизменяемому snapshot, читает ровно 4096 клеток и не зависит от GPU/генератора. Все семь руд заменяются камнем до выбора текстуры; тест подтверждает побайтное совпадение с камнем, включая исходные состояния руды. Структуры контейнеров, содержимое, авторитетные Cell/state и приватные seed в геометрический DTO не входят.

Цвет дальнего материала — представительная верхняя atlas-layer без полного набора граней и UV state; это сознательное приближение дальнего представления. Локальная геометрия и специальные модели остаются отдельными проходами.

```sh
source tools/env.sh
VK_ICD_FILENAMES="$PWD/.local/mesa/lvp-local.json" cargo test --locked -p render --test lod_gpu -- --nocapture --test-threads=1
cargo test --locked -p server --test lod
```

## Сервер → UDP → клиент → proxy job

`client/tests/far_geometry_stream.rs` проверяет двух настоящих UDP-ботов с общим `Connection`, задержкой 75±20 мс, потерями 2 % и перестановкой пакетов. Выбранный лист находится на x=1024 чанка; это **один далёкий лист, а не доказательство работоспособности всего горизонта 1024 чанка**. Архитектура полного горизонта требует запросов и данных верхних уровней либо heightfield clipmap.

В проверке дальний запрос точной near-page отклонён; приходят только публичные atlas-палитры и геометрические маски. Семь руд дают одну палитру камня. Отдельная страница с неизвестным ID сохраняет Unknown и не становится воздухом. Изменение только содержимого компонента запускает 0 дополнительных geometry jobs. Диагностическое удержание результата на 4 тика после настоящей упаковки позволяет детерминированно изменить мир между захватом и публикацией: сервер отбрасывает 2 устаревших результата, каждый клиент — 1 устаревший proxy job. Новая закрывающая проём клетка доходит до обоих клиентов.

Один фактический прогон: 8 задач, 6 публикаций, 32 768 прочитанных клеток и 2048 проб biome tint. Вход транспорта 8924 Б, выход 105 079 Б; суммарно 12 потерянных и 170 переставленных датаграмм. Переполнений 0, raw far-page кадров 0, приватный seed не найден в полученных пакетах/кадрах. Числа трафика зависят от повторов канала; проверяется корректность и отсутствие переполнения, не точный размер каждого прогона.

`PublicLodCache` работает на фоновом владельце: хранит сводки 4³, ограниченные защищённые страницы и immutable build tasks; stale-публикация не перезаписывает прежнее покрытие. Очередь coalescing не может запустить второй job того же ключа поверх ещё работающего первого и обойти лимит inflight. Новые GPU-представления загружаются выключенными; отсортированная пакетная смена 4-байтовых флагов проверяет весь бюджет до первой записи, затем единым фронтом скрывает старые и включает новые. GPU-тест подтверждает отказ 7-байтового бюджета и атомарную смену при 8 байтах.

```sh
cargo test --locked -p client --test far_geometry_stream -- --nocapture
cargo test --locked -p client --test lodcache
```

## Height-tile backend: проверен отдельно от живого горизонта

`render::height_tile` принимает только публичный тайл сервера: ключ
space/level/x/z, локальную монотонную версию, 289 целых высот, 37 байт
известности образцов, 256 atlas/tint и 32 байта защищённых клеток.
Неизвестные высоты обязаны быть нулём. Клиент не получает генератор или
частный seed. Уровень 0 покрывает 16×16 блоков; шаг сетки — 2^level.

`height_gpu` хранит 3276 байт данных и 64 байта дескриптора на тайл.
Вершины сетки не загружаются: 256 клеток строятся shader по vertex_index.
GPU отсекает тайлы и выполняет один indirect draw. Неизвестный угол или
protected-бит полностью подавляет соответствующие треугольники. Новую
группу можно загрузить выключенной и переключить вместе со старой после
готовности защищённых proxy; недостаточный бюджет не публикует часть
переключения. ABA и устаревшие/конфликтующие версии отвергаются.

Два CPU-теста формы/Unknown и отдельный тест кольцевого плана: **3 PASS**.
Native Vulkan `render/tests/height_gpu.rs`: **3 PASS**:

- По 9216 пикселям независимый oracle подтвердил сплошной тайл, 36 пикселей
  защищённой клетки и 144 пикселя вокруг неизвестного образца без заливки.
- Стык fine/coarse 2:1 с намеренными десятиблочными «зубцами» на нечётных
  fine-вершинах после стыковки побитно совпал с ровным эталоном. Отключённая
  стыковка изменила кадр; несовпадающие реальные coarse-образцы отвергнуты.
- Координаты 1e9 по X/Y/Z после целочисленного переноса дали тот же кадр,
  что локальная сцена. Следующий перенос X на 16 блоков записал только
  64 байта дескриптора, без изменения payload.

Фикстура публичных плоских тайлов для радиуса 1024 чанка реально прошла GPU:
259 тайлов, 340 посещённых узлов плана, 66304 неявных квадов / 397824
вершины; один draw, 259 indirect instances. Начальная загрузка — 865060
байт; правка одного тайла — 3340 байт. Десять повторных неподвижных наборов
дали 0 байт и 0 аллокаций. Это логические показатели, не измерение RTX ms.

Эта фикстура подтверждает backend и ограниченную стоимость колец. Она
**не подтверждает живой горизонт фактического мира**. Ещё нужны серверный
канонический public surface, сохранённый sparse-index всех cell-правок,
поток тайлов, версии/восстановление индекса и production-владелец
переключения. Защищённая coarse-клетка может быть большой: её нельзя
вырезать и заменить одной маленькой leaf-proxy. Полная совместимая замена
обязана покрывать весь вырезанный участок; постройки поверх действительного
грунта могут оставаться отдельными proxy без вырезания грунта.
Кольцевой план пока задаёт базовое распределение по расстоянию; полная
адаптация heightfield по экранной ошибке и её гистерезис ещё не заявлены.

Серверный `height_index` теперь имеет независимые **4 теста PASS** и Clippy.
Он хранит каждую committed cell-правку, включая AIR, с sourceTx; версия
меняется только у затронутых предков и соседей общего граничного образца.
Снимок `HIX2` (чтение прежнего `HIX1` сохранено) и ограниченная WAL-дельта `HID1` восстанавливают индекс без
чтения загруженных страниц. Morton-порядок даёт точный диапазон dyadic-тайла;
тест с 1000 посторонних колонок посетил только 4 необходимые колонки.
Для старого сохранения без индекса явно сохраняется MissingIndex, пока
каждая страница снимка не сравнена с серверным baseline в worker. Более
новые committed правки имеют приоритет над старым background-результатом.
Runtime/WAL-envelope kind5, серверные tile-workers и сеть подключает
отдельный владелец; этот helper сам их не подменяет.

## Владелец клиентского покрытия

`client::height_cache` принимает только публичные тайлы; генератор и чтение
точных клеток ему недоступны. Новая версия того же ключа загружается в отдельный
выключенный GPU-слот. Старый набор остаётся видимым до готовности всех источников,
стыков соседей и подтверждения точной защищённой геометрии. Переключение проходит
одной проверенной пачкой флагов; загрузочный бюджет не может показать половину
замены. Арена требует 1024 слота для активного и готовящегося набора.

Реальный GPU: план горизонта 1024 страницы — 259 тайлов / 340 посещений; одна
внутренняя правка — один payload, 3348 Б вместе с дескриптором/переключением.
Задержанная граница и защищённая геометрия удерживают прежнее изображение побитно.
Третий экземпляр ключа отклоняется, устаревшая версия игнорируется, конфликт
одинаковой версии отклоняется. 10 000 статичных опросов — 0 аллокаций/загрузок;
ожидание недостающего стыка также без аллокаций. Точное сетевое подключение,
согласование ближней области и игровой сценарий дальних построек продолжаются.

## Авторитетный baseline и требование замены

`gen::public_terrain_column` использует общие с настоящим `v4::base`
`base_materials/base_top`, включая склон, биом, берег и подводную почву.
Это **undecorated baseline**, без деревьев, частных руд и конечных spawn
моделей. 1944 колонки сравниваются с полными 18×18 scratch base: ground и
surface материалы совпали. 1000 отдельных запросов — 0 аллокаций.
Все 11 тестов gen и Clippy прошли; после выделения общей функции настоящий
native/WASM determinism повторно подтвердил четыре golden columns,
128 World ticks, 256 physics/entity ticks и movement replay 64.

`server::height_tile::build_canonical_tile` собирает 289 известных/Unknown
образцов и atlas/tint только на worker, без чтения World и генерации страниц.
Каждая сохранённая изменённая колонка дополнительно проверяется по точному
baseline в её координате. Правки полностью ниже нетронутого ground top
остаются скрытыми и не пробивают кратер через поверхность. Изменённая
поверхность, постройка или AIR-отверстие требуют точной замены. Конечные
spawn-области проверяются по полным bounds, включая детали между редкими
вершинами. Верхняя граница — 4096 колонок / 65536 сохранённых правок.

Защищённый coarse tile требует `Refine` в четыре дочерних тайла до level0.
Защищённый leaf не вырезает отдельный гигантский coarse cell: он требует
замены всей области 16×16 точной геометрией всех вертикальных страниц
от 0 до max(127, верх правки), не более 32 страниц. Само требование ещё
не доказательство готовности. Authority должна приложить полный manifest
PageId + source/view каждого публичного Geometry результата. Клиент
сохраняет прежнее покрытие до готовности всего manifest; неизвестная или
слишком высокая замена означает backpressure/более подробное покрытие.

Пять builder-тестов и Clippy PASS: сохранённые AIR/roof правки на X1024
переживают snapshot без загруженных страниц; локальные source stamps
меняются без чужих тайлов; подземная AIR не скрывает поверхность; sparse
structure между sample требует refinement; shared samples совпадают.
Wire, durability authority, баланс 2:1 после refinement, полный source/view
manifest, proxy coverage и настоящий полёт ещё связываются отдельными
владельцами. Эти проверки не объявляют живой горизонт 1024 завершённым.

Ближняя область имеет отдельную маску Unknown: `suppress_region` атомарно
выключает пересекающиеся тайлы до отрисовки при движении камеры, даже пока новый
план ещё строится. Последующая публикация старого плана не может включить их
обратно. GPU-проверка подтверждает отказ при нехватке 1 байта и переключения
4/8 Б без промежуточного изображения; естественные входы в пещеры не заполняются
высотным приближением. Фактическое подключение этого договора — в ViewHorizon.

Сквозной сетевой сценарий прошёл: два UDP-клиента, 75±20 мс/2% потерь и
перестановки пакетов, лист в 1024 страницах от игрока. Старый мир мигрировал 17 страниц
(69 632 сравнения только в рабочем потоке) и пересёк checkpoint-барьер. Скрытые руды
не создали ложных дыр; новая арка обновила высотный источник и потребовала
восемь точных публичных page/source/view сертификатов. Сырых дальних страниц,
ключа генерации и приватного компонента в ответах нет. Выгрузка страницы крыши
и реальный перезапуск сохранили источник постройки и закрытое небо над землёй.
Артефакт: `.local/artifacts/height-stream-tests.log`. Это не заменяет визуальный
прогон окончательного игрового клиента; его подключение продолжается.

## ViewHorizon и браузерные задания

`view::horizon` связывает height-cache с настоящими GPU proxy. Готовность
Column manifest проверяется по каждому GPU resident: source и view должны
точно совпасть. Семь из восьми страниц сохраняют прежнее изображение
побитно; stale view worker отбрасывается. Полная замена сохраняет воздух
арки. Перенос начала координат пишет только заголовки и сохраняет кадр
побитно. Отзыв geometry при недостаточном бюджете подавляет horizon draw
до атомарной инвалидизации; повторная корректная публикация восстанавливает
кадр. Сто idle pump — 0 байт и аллокаций.

Ближний регион всегда вырезан до точного terrain или Unknown. Persistent
near guard применяется и к старому покрытию, и к proxy до перехода камеры;
это не позволяет height-baseline закрывать естественные входы в пещеры.
Off-thread PlanTask уточняет protected hints, балансирует соседей 2:1 и
пересчитывает seams. Один проверенный 1024-план: 319 тайлов, 40 уточнений,
60 near cutouts, 788 415 проверок пар; верхняя граница — 4 000 000 пар.

Публичный packed Geometry DTO декодируется и превращается в proxy только
на worker. Главный поток хранит stamp/Arc и проверяет bounded результат.
CHJ1/CHR1 передаёт публичные masks/palette/indices; контрольный запрос
1085 байт, результат 726 байт, packed payload побитно совпал с native.
Обрезки, неверные ranks/indices и длины отвергаются; seed/raw Cell отсутствуют.
Отмена сохраняет immutable input для повторной попытки, 3 ошибки дают
явное состояние failure. View/Remote/native/browser hooks подключает
runtime; отдельная проверка helper ещё не означает завершение полёта M5.


## PXP2: A2C, прозрачные вырезы и полный тест стыка

Непрозрачный DDA теперь пропускает Cutout-клетки и работает без A2C. Cutout
строится в существующей фоновой задаче из публичной палитры через обычные
16-Б quad descriptors; GPU vertex pulling и аппаратный A2C рисуют эти грани
после непрозрачного фона. Это сохраняет реальную геометрию за частично
покрытыми сэмплами. CPU-вершины в игровом кадре не строятся.

Перспективный луч использует sample-qualified однородную clip-координату:
Dawn может оставлять builtin fragment XY в центре пикселя. Строгое сравнение
`GreaterEqual` сохранено, включая геометрию на дальней плоскости с глубиной 0.
Отклонённые варианты с четырьмя sample-mask проходами и первым Cutout
пересечением не выбраны; их отрицательные результаты сохранены в рабочих логах.

PXP2 имеет 36-Б заголовок и отклоняет PXP1. Максимум — 24 576 Cutout-квадов,
4096 элементов палитры, 432 808 Б payload / 432 858 Б с worker envelope. Это
проверено настоящим round-trip и помещается в существующий предел 450 000 Б.
Декодер проверяет длины, ранги, материалы, направления и границы квадов;
Unknown и вода по-прежнему не подменяются воздухом. Source stamp и аренды
worker-задач остаются прежними.

Четыре pipeline создаются при загрузке: два render и reset/cull. В кадре —
два групповых indirect-вызова без per-object bind. Списки непрозрачных объектов
и Cutout-квадов независимы. Ёмкость списка Cutout — половина размера payload
арены в байтах; непересекающиеся payload spans ограничивают общее число квадов.
При стандартных 1024 objects / 4 194 304 words все запрошенные GPU-буферы
занимают 25 432 208 Б, из них 8 388 608 Б — новый Cutout visibility. Общие текстуры
и память pipeline драйвера сюда не входят. Это резерв арен, отдельно от активных
данных H4; утверждение о +13,8% выше относится к активным данным старого
непрозрачного набора, а не ко всей GPU-памяти.

Повтор H4 (`render/tests/lod_gpu.rs`) сохранил все 8 294 400 пикселей,
1035 свидетелей воздуха и 450 твёрдого тела: 900 неявных квадов против 8270,
97 800 Б активных масок/палитр, 0 выходов по бюджету. Новый учёт shader даёт
33 177 600 лучей и 367 774 992 перехода DDA; старые 19 835 064 / 154 294 416
сохранены как историческое измерение другой реализации. Время RTX/FPS из
этих чисел не выводится.

Независимый Dawn oracle использует настоящие production WGSL/PXP2 и отдельный
целочисленный emitter всех единичных граней, без greedy/Proxy decoder. Все 12
случаев MSAA 1/4 × opaque, Cutout alpha 0/128/255, смешанный фон и дальняя
плоскость прошли с 0 различий покрытия и глубины (порог 1e-6; максимум 2,98e-8).
Контроль со строгим `Greater` теряет 9216 пикселей дальней плоскости в обоих
режимах. Проверять только верхнюю плоскость Cutout неверно: настоящие боковые
грани тоже могут задавать глубину.

Native дополнительно проверяет 1936/1849 независимых внутренних свидетелей,
смешанный фон и far plane, BITWISE rebase/удержание прежнего покрытия,
отказы upload/flag budget и 1000 статических prepare без allocations, frees,
uploads, cull или runtime compilations. Положительный allocator control
подтверждает включённую инструментацию. Для 4 objects / 65 536 words запрошено
394 400 Б GPU-буферов. `build_work()` возвращает измерения фоновой сборки;
после worker-декодирования они отсутствуют, а не выдумываются как нули.

Последние две команды включены в обязательный `tools/check.sh`. Полный
near/far oracle отдельно сравнивает каждый из 4 сэмплов, Near16/32, 75 реальных
near objects, Unknown/старые resident pages и вертикальный полёт. Его поддержка
задаётся независимым f64 пересечением с фактическим конечным footprint; только
внешний raster fringe, не принадлежащий ни одной поверхности, исключается
симметрично. Отрицательные контроли прежнего 5×5 выреза и удаления целой
вертикальной колонки сохраняются. Дальние Height/Proxy пока не включены в
caster set M4; этот отдельный пробел не закрывается тестами покрытия.
