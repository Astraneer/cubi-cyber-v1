# M5: сводки мира и маскированные прокси

Первый H4 с сохранением точных мешей провалил бюджет. Альтернатива H4b теперь проверена настоящим GPU: геометрия состоит из шести неявных квадов коробки, fragment shader проходит маску занятости и пишет глубину фактической поверхности. Сам по себе этот прототип ещё не означает завершение M5: нужны подключение дальнего потока сервера и полёт в игровом клиенте.

`render::lod_gpu::LodProxyGpu` использует стабильные слоты с поколениями, арены данных, собственную compute-компактацию видимых объектов и один indirect draw в общем HDR/MSAA 4× проходе terrain. Данные приходят только из `PublicPage`, очищенного от закрытых сведений. Unknown не превращается в воздух: неполные данные отклоняются до замены предыдущего покрытия. Вода сохраняет отдельный тип, но этот непрозрачный backend её отклоняет для отдельного водного прохода.

На GPU хранятся маска занятости, префиксы popcount, битовые индексы палитры и пары atlas-layer/tint. Лишняя маска Known не передаётся: все 4096 входов проверяются до упаковки. Служебная таблица объекта занимает 256 байт, включает прямую/обратную матрицу и границы. Ray traversal ограничен 46 переходами на сэмпл. Мип выбирается по проекции размера клетки. По желанию загрузки подключаются стабильные тени M4 и публичный RGB/skylight объекта; режим инструментирования явно добавляет счётчики fragment shader.

## Измерение H4 на программном Vulkan

Один набор из 50 построек используется CPU- и GPU-проверками. Для каждой постройки проверены уровни 2/4/8 и шесть сторон — 900 изображений 96×96. Независимый целочисленный проход по соответствующим колонкам задаёт ожидаемое покрытие; сравнение учитывает настоящий MSAA-кадр и фон неба.

| Показатель | Результат |
|---|---:|
| Переходы | 150 |
| Проверенные пиксели покрытия | 8 294 400 |
| Свидетели воздуха / твёрдого тела | 1035 / 450, потеряно 0 |
| Квады прокси / исходный coarse mesh | 900 / 8270 |
| Полезные данные масок/палитр | 97 800 Б суммарно |
| Метаданные 150 объектов | 38 400 Б |
| Консервативный эквивалент 16-Б дескрипторов коробок | 14 400 Б; фактически коробка не требует quad buffer |
| Настоящие вызовы MSAA-лучей | 19 835 064 |
| Переходы DDA | 154 294 416 |
| Выходы по превышению бюджета | 0 |

Отдельное окно проверено по всем 9216 пикселям, включая отверстие; отказ upload-бюджета сохраняет прежний кадр. Проверка палитры охватывает 1/2/3/5/17/37/180 групп материалов и пересечение битовых индексов через границы слов. Ввод Unknown, воды и неизвестного atlas layer не подменяет предыдущую геометрию.

Сумма масок и метаданных — 136 200 Б. При консервативном добавлении 14 400 Б коробок — 150 600 Б против 132 320 Б исходных квадов, +13,8 %. Это активные полезные данные, а не вся зарезервированная GPU-память: арены и visibility имеют отдельную явную вместимость. Шесть квадов переносят работу во fragment shader; число лучей и шагов не скрывается. Миллисекунды RTX не измерены.

## Дальний поток и границы

Обычный горизонт использует сводки 4³ фактического мира. Только выбранные защищённые листья получают сжатые публичные геометрические маски и atlas-палитры. `server::lod::geometry_from_page` работает в задаче по неизменяемому snapshot, читает ровно 4096 клеток и не зависит от GPU/генератора. Все семь руд заменяются камнем до выбора текстуры; тест подтверждает побайтное совпадение с камнем, включая исходные состояния руды. Структуры контейнеров, содержимое, авторитетные Cell/state и приватные seed в геометрический DTO не входят.

Цвет дальнего материала — представительная верхняя atlas-layer без полного набора граней и UV state; это сознательное приближение дальнего представления. Локальная геометрия и специальные модели остаются отдельными проходами.

```sh
source tools/env.sh
VK_ICD_FILENAMES="$PWD/.local/mesa/lvp-local.json" cargo test --locked -p render --test lod_gpu -- --nocapture --test-threads=1
cargo test --locked -p server --test lod
```

## Сервер → UDP → клиент → proxy job

`client/tests/far_geometry_stream.rs` проверяет двух настоящих UDP-ботов с общим `Connection`, задержкой 75±20 мс, потерями 2 % и перестановкой пакетов. Выбранный лист находится на x=1024 чанка; это **один далёкий лист, а не доказательство работоспособности всего горизонта 1024 чанка**. Архитектура полного горизонта требует запросов и данных верхних уровней либо heightfield clipmap.

В проверке дальний запрос точной near-page отклонён; приходят только публичные atlas-палитры и геометрические маски. Семь руд дают одну палитру камня. Отдельная страница с неизвестным ID сохраняет Unknown и не становится воздухом. Изменение только содержимого компонента запускает 0 дополнительных geometry jobs. Диагностическое удержание результата на 4 тика после настоящей упаковки позволяет детерминированно изменить мир между захватом и публикацией: сервер отбрасывает 2 устаревших результата, каждый клиент — 1 устаревший proxy job. Новая закрывающая проём клетка доходит до обоих клиентов.

Один фактический прогон: 8 задач, 6 публикаций, 32 768 прочитанных клеток и 2048 проб biome tint. Вход транспорта 8924 Б, выход 105 079 Б; суммарно 12 потерянных и 170 переставленных датаграмм. Переполнений 0, raw far-page кадров 0, приватный seed не найден в полученных пакетах/кадрах. Числа трафика зависят от повторов канала; проверяется корректность и отсутствие переполнения, не точный размер каждого прогона.

`PublicLodCache` работает на фоновом владельце: хранит сводки 4³, ограниченные защищённые страницы и immutable build tasks; stale-публикация не перезаписывает прежнее покрытие. Очередь coalescing не может запустить второй job того же ключа поверх ещё работающего первого и обойти лимит inflight. Новые GPU-представления загружаются выключенными; отсортированная пакетная смена 4-байтовых флагов проверяет весь бюджет до первой записи, затем единым фронтом скрывает старые и включает новые. GPU-тест подтверждает отказ 7-байтового бюджета и атомарную смену при 8 байтах.

```sh
cargo test --locked -p client --test far_geometry_stream -- --nocapture
cargo test --locked -p client --test lodcache
```

## Height-tile backend: проверен отдельно от живого горизонта

`render::height_tile` принимает только публичный тайл сервера: ключ
space/level/x/z, локальную монотонную версию, 289 целых высот, 37 байт
известности образцов, 256 atlas/tint и 32 байта защищённых клеток.
Неизвестные высоты обязаны быть нулём. Клиент не получает генератор или
частный seed. Уровень 0 покрывает 16×16 блоков; шаг сетки — 2^level.

`height_gpu` хранит 3276 байт данных и 64 байта дескриптора на тайл.
Вершины сетки не загружаются: 256 клеток строятся shader по vertex_index.
GPU отсекает тайлы и выполняет один indirect draw. Неизвестный угол или
protected-бит полностью подавляет соответствующие треугольники. Новую
группу можно загрузить выключенной и переключить вместе со старой после
готовности защищённых proxy; недостаточный бюджет не публикует часть
переключения. ABA и устаревшие/конфликтующие версии отвергаются.

Два CPU-теста формы/Unknown и отдельный тест кольцевого плана: **3 PASS**.
Native Vulkan `render/tests/height_gpu.rs`: **3 PASS**:

- По 9216 пикселям независимый oracle подтвердил сплошной тайл, 36 пикселей
  защищённой клетки и 144 пикселя вокруг неизвестного образца без заливки.
- Стык fine/coarse 2:1 с намеренными десятиблочными «зубцами» на нечётных
  fine-вершинах после стыковки побитно совпал с ровным эталоном. Отключённая
  стыковка изменила кадр; несовпадающие реальные coarse-образцы отвергнуты.
- Координаты 1e9 по X/Y/Z после целочисленного переноса дали тот же кадр,
  что локальная сцена. Следующий перенос X на 16 блоков записал только
  64 байта дескриптора, без изменения payload.

Фикстура публичных плоских тайлов для радиуса 1024 чанка реально прошла GPU:
259 тайлов, 340 посещённых узлов плана, 66304 неявных квадов / 397824
вершины; один draw, 259 indirect instances. Начальная загрузка — 865060
байт; правка одного тайла — 3340 байт. Десять повторных неподвижных наборов
дали 0 байт и 0 аллокаций. Это логические показатели, не измерение RTX ms.

Эта фикстура подтверждает backend и ограниченную стоимость колец. Она
**не подтверждает живой горизонт фактического мира**. Ещё нужны серверный
канонический public surface, сохранённый sparse-index всех cell-правок,
поток тайлов, версии/восстановление индекса и production-владелец
переключения. Защищённая coarse-клетка может быть большой: её нельзя
вырезать и заменить одной маленькой leaf-proxy. Полная совместимая замена
обязана покрывать весь вырезанный участок; постройки поверх действительного
грунта могут оставаться отдельными proxy без вырезания грунта.
Кольцевой план пока задаёт базовое распределение по расстоянию; полная
адаптация heightfield по экранной ошибке и её гистерезис ещё не заявлены.
