# H2 — отклонённый кандидат свёртки рецептов

Проверенный кандидат не достиг порога 4× на полной линии. Выбран подробный авторитетный тикер. Результат относится к этому кандидату, а не ко всем возможным будущим автоматам связанных сетей.

Эксперимент исполнял настоящий `MachineRuntime` над World: ORE-2 из 10 единиц сырой руды, энерго- и газовая сети, сундук после двух транспортёров, три настоящих снимка окна каждый тик, подтверждаемая история видимых грузов и кодирование настоящего WAL Batch. Двадцатый слиток приходил на **4671**: проверенный тик 4632 плюс 39 тиков двух труб. Четыре одинаковых запуска дали одинаковые выходы и хеши, всего **133 668 событий**.

|---|---:|
| Тиков | 4671 |
| Событий владельца / тиков рецептов | 33 417 / 27 986 |

Кандидат проецировал внутренности Crusher/Enrich/Smelter, отдельно учитывал пустой eject-счётчик по модулю 11 и прекращал свёртку при реальном изменении энергии, предметов или границе операции. Передача энергии потребовала 11 593 точных обновления из 14 013 тиков. Оптимистическая верхняя граница **по числу событий** — `33417 / (33417 − 1998) = 1,063592×`, ниже 4×. В самом ядре при этих наблюдениях `14013 / 13636 = 1,027647×`. Длинный интервал 627 оказался ожиданием, а не производительным выигрышем.

Это граница счётчика операций этого кандидата, не доказательство верхней границы ускорения CPU. Время Debug-владельца в облаке составляло около 4,05–4,62 с на запуск; оно не является замером оборудования заказчика. Поле эксперимента `attempted_elapsed` суммирует перекрывающиеся запросы проекции: делить его на переходы как независимое время симуляции нельзя. Старые 17,604× чистого ядра и 2048 изолированных копий не доказывали стоимость полной линии.

По §11 невыбранные `machines::events`, отдельная WakeQueue, её экспорт и три теста этого параллельного пути удалены из рабочего API. Проверка нулевых аллокаций подробного тикера сохранена. Подробные рецепты, топология, транспорт, атомарный WAL и эталоны 837/1035/4632 проходят повторно; ленивые live-компоненты без материализации всех наблюдателей не включены.

Архив воспроизведения: `.local/artifacts/h2-fullchain-negative.zip`, 885 909 байт, 296 файлов. Он намеренно игнорируется Git и содержит самостоятельный снимок исходников эксперимента, старое ядро только для воспроизведения, pinned lock, точные результаты четырёх запусков и список SHA256 файлов.

SHA256: `293104e6e72d16f798c1992a98f0059a60b8f2e1617f96f159e4e680f33b940a`.

Проверенная команда в распакованном снимке (Rust 1.90.0, установленный Cargo cache):

```sh
cargo run --locked --offline --manifest-path .local/experiments/h2-fullchain/Cargo.toml
```

В этой среде сначала выполнялся `source /workspace/cubi-cyber-v1/tools/env.sh`. Четыре запуска с этой точной командой подтвердили хеш потока World/WAL/окон/видимых грузов `10d04bc2b37ea196cedd6062542fa5ff1b23a02032fa4c62083acae53b565db9`. CRC архива проверен. Построение и проверка клиентских экземпляров сами по себе не заменяют полный сетевой игровой прогон M9.
