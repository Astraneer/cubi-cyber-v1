# M11: общий Rust UI

`ui::layer::UiLayer` использует одинаковые экранные состояния, обработку ввода и wgpu
рисование в native и WASM. Проверены экраны приветствия, паузы, настроек, HUD, инвентаря,
верстака, сундука, печи, машины, NEI/рецептов, локальных ресурсов, Перекрёстка, чата и Tab.
Стиль — «Тёмный камень». Шрифт VoxelPixel из белого списка: WOFF1 распаковывается в
ограниченный SFNT, glyph atlas строится заранее; встроенное уведомление CC0 сохранено.
Текстуры блоков взяты из разрешённого атласа, символы предметов — новый код проекта.

Одна UI pipeline создаётся при подготовке; статическая геометрия и атлас сохраняются.
10 000 неизменившихся кадров не выделяют память, не строят вершины и не загружают GPU
данные. Настоящий программный Vulkan отрисовал меню с 3044 проверенными светлыми пикселями
текста. Изображение: `.local/artifacts/m11-ui-menu.png`.

Бот-сценарии проверяют переходы меню, независимость пресетов от звуковых настроек,
Unicode-поиск NEI, рецепты/применения, чат и Tab, конфликты физических клавиш, UI scale и
соответствие hit-test масштабу, атомарное чтение сохранённых предпочтений, отсутствие
выдачи творческих предметов обычному игроку. Каталог команд берётся из `net::command_catalog`,
а окончательные права проверяет сервер. Схема настроек и AutoQuality — единая ранее
подготовленная `ui::settings`; MSAA/тени не меняются автоматикой.

UI хранит копию авторитетных 41 слота, курсора, 9 клеток крафта и не более 54 слотов окна.
Нажатия создают типизированные intents с ID окна, версией окна и версией инвентаря;
реальные вещи в UI не изменяются. `server::ui::WindowState` подготавливает detached планы
переноса/половины стопки/быстрого переноса, NEI «+», единичного/массового крафта и закрытия.
Курсор, craft и контейнер имеют строгий WND1 codec 407 Б. Планы проверяют все входы перед
атомарным apply; overflow при закрытии возвращается явными drops для той же durable
транзакции. Новое открытие получает новый server epoch, включая обычный инвентарь.

Семь тестов владельца проверяют сохранение вещей, stale/ABA, броню, запрещённую вставку в
выход печи, извлечение половины выхода, отсутствие придуманных ингредиентов, точный craft
и codec continuation/повреждения. Они дополняют 15 проверок UI (4 settings + 1 font + 8
интеграционных, включая реальный GPU, + 2 profiler). Native Clippy и WASM compilation проходят.

Отдельный браузерный бот проверил настоящее WebGPU-изображение и ввод мышью/Unicode:
3044 светлых пикселя в приветствии, 6560 в настройках, 2147 в инвентаре, 6808 в F3;
поиск уменьшил 180 предметов до 19. Артефакты: `.local/artifacts/m11-web-*.png` и
`m11-ui-browser-smoke.json`. Это отдельный проверочный shell, не основной игровой вход.

Общий F3 читает `telemetry::flight::FlightRecorder`: 8 стадий CPU, 16 GPU-проходов,
очереди/возраст заданий, память и работу. Неизмеренные значения остаются «не измерено».
График хранит максимумы 120 временных корзин за 10 секунд; краткие скачки не усредняются.
Совпавшие наблюдения помечены без утверждения причины. Два теста проверяют неизвестные
GPU-времена, сохранение скачка и отсутствие аллокаций/перестроения в 10 000 одинаковых
кадрах. `client::ui_bridge` связывает физические клавиши, захват меню/чата, чувствительность
и инверсию, категории звука и подтверждённый инвентарь; доступность протокольного маршрута
остаётся явной. Полоса еды появляется только при наличии авторитетного значения.

Приёмка M11 **ещё не завершена**. Нужны подключение UiLayer/ввода/действий к shell после
H1, server protocol + SavedPlayer/WAL binding WindowState, открытие реальных блоков и
транзакция контейнера, реальные chat/roster updates, передача F3/F8 данных самописца из shell, настройки
подготовленных вариантов рендера и включение локального импорта/звука в меню. Программный
pixel-тест и отдельные планы не выдаются за законченный игровой сценарий. Зелёный CI
требуется отдельно по SPEC.
