# M11: общий Rust UI

Обе платформы используют `ui::layer::UiLayer`: Welcome, Loading, паузу,
настройки, HUD, инвентарь, окна верстака/сундука/печи/машин, NEI, локальные
ресурсы, Перекрёсток, чат, Tab и F3. Native/WASM отличаются тонкими адаптерами
ввода, транспорта, файлового picker и аудио. Явный `--scene forest` /
`?scene=forest` сохраняет отдельный диагностический профиль.

Шрифт VoxelPixel из белого списка распаковывается в ограниченный SFNT;
glyph atlas и одна UI pipeline готовятся заранее. CC0 уведомление сохранено.
Статический UI в 10 000 повторениях не выделяет память, не строит вершины и
не загружает GPU. UI scale меняет одновременно изображение и hit-test.

## Авторитетные данные и ввод

UI отображает подтверждённые 41 слот, курсор, девять клеток craft и до 54
слотов окна. Нажатие создаёт typed intent с ID/epoch окна и версиями окна и
инвентаря. UI не меняет настоящие предметы. Сервер проверяет права и stale
состояние, сохраняет планы в одной durable транзакции и только затем
публикует результат. Новое открытие получает новый epoch; закрытие возвращает
предметы или явные drops. WND1/XREF сохраняет ссылки stateful предметов.

IAT1 передаёт только факты собственного слота: режим конфигуратора, заряд
планшета и тип сохранённой машины. Mapper требует точного совпадения
revision/slot/item/payload. Без факта показывается «Сохранённый заряд/состояние»;
приватное содержимое и opaque ID в обычный tooltip не выводятся. Еда лечит
напрямую: выдуманного hunger bar нет. Команды берутся из
`net::command_catalog`, окончательные права проверяются сервером.

Чат/меню захватывают клавиши. Shift+N использует физический Shift независимо
от переназначения Sneak; короткий RMB и Shift+RMB сохраняют press/modifier до
потребления. При временной Capacity bridge удерживает одну исходную команду
без преждевременного ActionId, допускает локальное меню/disconnect/F8 и
отправляет её один раз после освобождения квоты. Тест 10 000 заблокированных
попыток не выделяет память и сохраняет первоначальный ActionId.

Native WebSocket worker и GUI используют один `Arc<Mutex<RemoteSession>>`.
Worker принимает данные прямо в bounded typed-кэши с объединением по ключу,
отправляя до 64 исходящих перед чтением до 32 входящих. GUI освобождает guard
до acquire/encode/submit. Сырой GUI FIFO удалён; дополнительной Replica нет.
Browser onmessage аналогично сразу передаёт данные в одну Connection,
а ограниченная CPU-фаза отдельно меняет Scene. comparative-тест на настоящем
сервере доказал прежний HOL: при GUI-паузе 4 с legacy за 20 с видел только
Accepted1 при уже принятых 2/3; shared owner получил 1/2/3 за два GUI-прохода.
Лимиты не увеличивались; варианты 8/250/1000 мс также прошли.

## Настройки и кадры

Схема содержит 32 поля; чтение legacy 29/30 полей атомарно мигрирует только
старые значения по умолчанию. Явные Custom/Heavy сохраняются. Requested
значение и actual receipt различаются: FOV, Bob, чувствительность, инверсия,
звук, Hints и UI scale подключены; требующие ресурсов параметры проходят
асинхронный Loading с сохранением личности и предметов. Неудачный preflight
оставляет прежний профиль. Animations скрыт до настоящей реализации.

Подготовленные backend дают фактические receipts для MSAA4/SMAA1,
Shadow enable/cascades/resolution, SSAO, SSR, Cloud, GI, Scale, Exposure,
ExposureMode Auto/Manual и SkyStyle A/B/C. Личное время server/day/night/
dawn/dusk использует один подтверждённый clock для Shadow и Environment;
оно не меняет время сервера. Horizon/LOD подтверждаются после commit нужного
покрытия. Near квантуется страницами: 4…16 дают эффективные 16 блоков,
24/32 — 32; 48/64 явно отклоняются при текущем cap256. Near receipt требует
реального Scene и ready; новый протокол ForgetPage требует согласованной
пары сервера и клиента. SMAA подробно описан в [SMAA.md](SMAA.md).

Hold60 получает только реальные presents и завершённый полный GPU-интервал;
сохранённые пользовательские предпочтения не меняются. Pending/failed
изменение не считается применённым. MSAA и выключение теней не используются
автоматикой. Реальный автоматический переход остаётся отдельной приёмкой.

Pause/Settings/Resources/Crossroads рисуют cached HDR + Tone/UI, продолжая
CPU/network/jobs. Непоказанные камера, мир и edits не подтверждаются.
Незавершённый near/far join сохраняет прежний HDR. До первого HDR Loading
показывает настоящий clear с ready=false, пока CPU-derived inputs и общий
upload budget не готовы; Shadow/content проверяются следующим настоящим
scene encode. GPU-тесты проверили 20 clear кадров без terrain/HDR stamps,
затем настоящий прогресс, и 20 побитно одинаковых cached кадров без
histogram/bloom/uploads. Строгий product timeout 120 с не увеличен.

F3 читает FlightRecorder: 8 CPU стадий, 16 GPU интервалов, очереди/работу/
память; неизвестные значения остаются неизвестными. График сохраняет пики
за 10 секунд. F8 содержит полный фактически отправленный GPU-интервал
вместе с UI (`gpuTotalComplete`), а `movementReplay` — публичные movement
шаги и checkpoints для независимого offline повторения. Replay всего
рендера/UI остаётся unavailable; причинность из совпавших наблюдений не
утверждается.

## Проверенные продуктовые сценарии

Это отдельные immutable component-проверки; все имеют
`fullProfileAccepted:false`, старый far-privacy сервер и не принимают
UDP/M5/M6 либо аппаратные FPS. Source/binary hashes сохранены с результатами.

- Browser: ручные Horizon16/SSAO0/Cloud0/GI0/SSR0, 125 LIGHT страниц,
  inventory/chat/Tab/F3, локальные ZIP и `.minecraft`, та же личность после
  reconnect/Quit. Импорт дал 29 777 magenta пикселей. За 417 WebSocket
  сообщений не было HTTP/утечек canary. F8: 13/13 полных GPU-интервалов,
  completeWindow=true, 223 offline повторённых movement шага.
  Архив: `.local/artifacts/ui-components-1793006782530798425`.
- Native, стек 1 МиБ: все 36 Owner действий — log → ровно 4 planks,
  80 мс RMB chest placement/audio, deposit/reopen/withdraw без потери вещей,
  NEI64 stone, пять режимов конфигуратора и обратный Shift+N. Настоящие
  day/night кнопки изменили 194 937 пикселей; Exposure25→50 — 201 422.
  MSAA4→1 и Scale100→85 сохранили личность и 69 предметов, HDR стал
  816×459 при UI960×540. F8: 16/16 полных GPU-интервалов, 75 шагов /
  10 checkpoints, offline hash `7c0e784c500a76d8`, complete_10s=true.
  Архив: `.local/artifacts/native-inputs-scale-1793011992985965806`.
  Этот архив предшествует добавлению SMAA и доказывает только один отсчёт.
- Native visual choices, стек 1 МиБ: пять настоящих переключений
  Auto→Manual, A→B→C, Manual→Auto, C→A; после Loading actual owner getters
  совпали, личность и один предмет сохранились. F8: 87/87 полных GPU
  интервалов, 184 шага / 31 checkpoints, offline hash `02a49a6be1878298`,
  complete_10s=true. Архив:
  `.local/artifacts/native-visual-choices-1793013519345959870`.

Компонентные тесты дополнительно проверили настоящий Dawn/native вывод UI,
Unicode/NEI/recipes, окно/чат codec→Connection→UI, права, stale/XREF/IAT,
нулевые аллокации, AA/AO/SSR/GI/Scale и варианты экспозиции/небесных тел.
Полный ClientView SMAA проверил действующий owner, четыре Post прохода и
1000 неизменившихся CPU/upload фаз без аллокаций/работы. Это ещё не новый
продуктовый запуск через обе оболочки.

Остаются свежая согласованная server/native/WASM пара с ForgetPage/RawContext,
реальные SMAA/Near32 интерфейсные сценарии, строгий default/Heavy1024 full
profile и итоговый CI. TAA с настоящими object motion vectors разрабатывается
отдельно. Полный replay рендера/UI и аппаратные показатели не заявлены.
