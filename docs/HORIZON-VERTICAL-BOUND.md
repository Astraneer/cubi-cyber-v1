# Вертикальная оценка ошибки высотного горизонта

Сертификат ограничивает вертикальное смещение верхней поверхности. Произвольные воксельные стены, уступы и подводная геометрия требуют отдельной проверки представления: эта формула их не восстанавливает.

Пусть E — сумма ошибки высоты и шва, D — диагональный тангенс поля зрения, k=sqrt(1+D²), F — фокус в пикселях, d — расстояние от коробки положения глаза до AABB представления. Для S=sup|cameraForward dot worldY| по неизменной угловой корзине определим N=max[0≤s≤S](sqrt(1−s²)+D*s). Верхняя граница равна **F*E*N/(d/k−E*N/k)**; неположительный знаменатель даёт бесконечность. Положительный знаменатель гарантирует положительную глубину обоих концов смещения. Достаточно принадлежности AABB только точки представления; более сильный знаменатель d/k−E*S без дополнительной предпосылки небезопасен. S=1 выполняет прежнюю ветку вычислений с теми же битами.

Общие проекции и старые CHJ4 используют S=1. CHJ5 добавляет один конечный скаляр [0,1], сохраняя прежние проверки размеров, квот и порогов; CHR4 не меняется. Отправитель и worker должны собираться из одного снимка. Runtime использует настоящую ось камеры после bob/third-person, корзины yaw45°/pitch10°, запас для всей корзины и округление S наружу; у полюсов S=1. Неконечные промежуточные значения не публикуются. Неопределённая видимость остаётся видимой, а неопределённая ошибка — бесконечной.

Самодостаточная публичная проба содержит настоящий запрос CHJ4 и обычный ответ HTI2 для отсутствовавшего крупного tile. Она использует production-декодеры и расчёт шва. До исправления:22 предельных листа,50,2896px. После:0 отсутствующих сертификатов,0 предельных листьев,31,7857px≤32,62 из прежних64 точных колонок и ни одного нового запроса. Первоначальный интерес уже содержал512 страниц. Это проверка выбора; она не доказывает GPU commit, вход в игру, сходимость всех seed/дальностей или общую геометрию H4.

Восемь тестов проверяют pinhole-проекцию при произвольном roll, границы корзин, полюса, числовые переполнения, совместимость CHJ4/CHJ5 и настоящую публичную пробу. Native workspace/all-targets и shipping WASM Clippy, форматирование прошли в отдельном target, связанном только с этим абсолютным путём исходников. Миллисекунды целевого железа не измерялись.
